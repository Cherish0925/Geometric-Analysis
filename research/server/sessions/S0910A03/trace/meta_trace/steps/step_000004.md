## Deep-Reasoning

本步建立了三项新的定量几何约束，并在 TTCS 核验和 Codex 定量分析的推动下，精确定位了负临界分支中完成证明所缺的唯一障碍。

**完成方估计（Weyl profile L² 集中）。** 从 completion square ∫(s+8√6|W+|)²→0 与一致 s→−4 推出 ∫(|W+|−1/(2√6))² dμ = O(Aδ²)。校准值 1/(2√6) 恰为 Kähler–Einstein 值 2/√6 的四分之一。对任何收敛到 KE 几何的区域 U，体积分数为 O(δ²)→0。这一结果独立地被 S0910A01 在 Step 5 中用代数方法核验并确认。

**气泡限制。** 对固定 A（固定拓扑），任意 Vol(U)→0 的子集上 W+ 能量趋零（利用 profile + Weyl 尺度不变性）。因此光滑非塌缩放大极限同时具有 Ric=0 和 W+=0，即局部 hyperkähler。这比此前仅要求 Ricci-flat 更强。

**Armstrong–LeBrun 矛盾（已修正）。** 若在固定临界 Ishida–LeBrun 流形上 δ_i→0 的序列有光滑收敛，则极限满足精确 K=A 等号。LeBrun 2006 Proposition 3.8 的 Hölder 等号链直接给出 |Φ|²=const>0（不依赖独立的强最大值原理），从而产生饱和 almost-Kähler 结构。Corollary 2.5（Armstrong）迫使 Einstein+饱和→Kähler–Einstein，但 |W+|²(KE)=2/3 与 profile 的 1/24 矛盾。或者，极限本身是 M 上的 Einstein 度量，与 Theorem 7 矛盾。

**关键修正。** TTCS 核验指出此前声称的 |Φ|² 强最大值原理论证不完整：在 |Φ|²=0 的点，Weitzenböck 给出 |∇_A Φ|=0，但 Dirac 方程 D_A Φ=0 的唯一延拓只对无穷阶消失成立，二阶消失不够。spinor 可能有孤立零点（例如 Kähler 曲面上全纯截面的零点）。修正后的论证应完全通过 Prop 3.8 的等号刻画（Hölder 等号迫使 |Φ|⁴=const），而非分离的最大值原理。这一修正已发送给会话组并被 A01 接受。

**非塌缩缺口。** TTCS 生成和核验分支独立确认：|Ric|≤Λ + Vol(M)≥V₀ 在固定流形上不能推出逐点非塌缩。明确反例：Σ_g×Σ_{g'} 上沿一个因子退化双曲度量，有精确 Ric=−g、固定体积、但短测地线附近局部塌缩。但此反例是 Kähler 的，|W+|=2/√6，被 Weyl profile 排除。因此 Weyl profile 作为塌缩模型的几何过滤器运作：已知的 Ric=−g 塌缩模型（乘积曲面、KE 块体、共形平坦 cusp）均不满足 profile。精确的开放问题是：是否存在 |W+|≈1/(2√6) 且 Ric≈−g 的未知塌缩模型？

**Codex worker 结果。** 成功完成的 Codex exec 任务给出了精确的缺陷分解：Δ_a≤108π²R≤72π²Aκ/(1−κ)，其中每个单项缺陷（Hodge 投影、spinor 振幅、Weitzenböck slack、Kato 项、最低 W+ 特征线）均可独立控制在 4Δ_a/27 以内。Walsh 极化给出空间 L¹ 正交性：∑|x_r|²≈𝓛²，⟨x_p,x_q⟩≈0，迫使 canonical 类在正则区域空间分离。Sharp conditional theorem 表明固定 boundary 流形上 δ_i→0 不能同时有一致 C^{2,α} harmonic radius 和一致直径界。Step 3 所有数值常数均被独立核验正确。

**正分支。** S0910A02 在 Step 5 提出全维正分支程序，利用 Myers 直径界。与 A02 的交流确认：(1) 在 LeBrun/SW 流形上正分支为空（s>0 杀死 SW）；(2) 对无 SW 阻碍的流形，需要正 Ricci 夹逼下的体积下界，这是 CGB 不能直接给出的。正分支有结构性优势（一个缺口而非两个）。

当前精确归约：负分支临界族上的完整定理只差一个步骤——证明满足 Weyl profile 约束的度量不存在宏观崩塌。这等价于证明某种 capacity 或 Sobolev 不等式，或直接分类满足 Ric≈−g、|W+|≈1/(2√6) 的 4D 塌缩几何。
