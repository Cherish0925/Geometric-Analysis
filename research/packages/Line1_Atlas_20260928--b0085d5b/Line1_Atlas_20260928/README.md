# 使用说明

先读 `00_Line1_Research_Atlas_20260928.md`，再按其链接进入专题附录。`03_N1_Complete_Inheritance.md`含本次完整继承核查与有界平方短缺推论。

`01_Knowledge_Graph.json`含56个科学结果/问题节点、20个阅读卷节点和126个原稿来源条目；边区分证明依赖、历史加强、反例限制、候选路线与纯索引关系。`02_Source_Index.csv/json`保留原始路径、SHA-256和阅读卷定位。79个早期条目与47个最新条目有重复及版本关系，不能称为126个独立成果。

`sources/`中的原始阅读卷逐字节保留。旧卷自带链接仍相对于原项目路径；请用来源索引找到对应卷和原稿序号。正文与附录的“原稿已证”表示该原稿已提供证明，不表示本轮重新证明全部PDE分析，也不替代文献优先性查新。

此次检查了来源副本字节一致性、图谱引用完整性及本次新N1推论。数值回执含失败与未收敛尝试，未将其提升为定理证明。没有重复执行无关数值搜索。

后续维护：在同一知识图谱上增加或更新节点；每次升级必须写清原假设、结论变化、依赖及误差尺度。被反例否定的只标记准确过强命题，保留原有效定理。
