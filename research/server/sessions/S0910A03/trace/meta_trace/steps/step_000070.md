This quantifies the geometric incompatibility: the evolution equations alone cannot ensure near-Einstein solutions. The full Einstein system requires the DeTurck gauge with 5 unknowns.

The Li-Liu deformation analysis (from TTCS) showed that coordinate-level slices of Li-Liu ASD Einstein metrics satisfy |S|² ≥ 8/3, far from totally geodesic. Near-geodesic T³ requires finite-amplitude ASD breaking or strongly tilted graph slices, which must be analyzed through the mixed-end Lichnerowicz operator.

The decisive open question is now sharply formulated: does the exact analytic Koiso extension survive to t=∞ for some scalar-minus-six T³ center? If yes, the graph manifold construction pipeline is complete (Koiso half-core → truncation at R = (1/2)log(6/δ) → terminal layer → anisotropic quotient → peripheral cover → graph gluing). If no, only approximate cores with controlled defect can work, and the logarithmic length bound is necessary. The isotropic case (flat T³, H = 3tanh(t)) survives globally, and the decay of intrinsic curvature terms as e^{-2a} suggests stability of the cusp attractor for nonflat centers. A rigorous stability analysis or a DeTurck BVP numerical experiment would resolve this.
