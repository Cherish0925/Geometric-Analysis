## Deep-Reasoning

This step corrected the representation-theoretic foundation of the current positive-branch Gate 1/Gate 3 program. The global Yau--26 target remains unchanged and unresolved: dimensions 2 and 3 are ordinary-theorem settled but not Lean-formalized, dimension 4 has crossing/zero intervals refuted while strict positive and strict negative branches remain open, and no dimension n>=5 refutation or proof is available. The current local four-dimensional positive line is not a proof or refutation of Yau--26; it is a controlled test of whether mixed Eguchi--Hanson resolutions of the product Einstein orbifold can be exact Einstein desingularizations, or are locally obstructed. Its value lies in sharpening the obstruction calculus and preventing false coefficient stories from contaminating the main problem.

The Step 94 conclusion that the local second obstruction on the product rank-one kernel vanishes is mathematically plausible, but the proof language was faulty where it tried to infer vanishing of the full projected local O(t^2) vector from SO(2) transitivity. A projected obstruction is not a fixed vector in K; it is an equivariant homogeneous map K -> K, and maps such as z -> f(|z|)z can be equivariant. The correct reason is weight-theoretic. For the product orbifold, independent rotations of the two sphere factors form a T^2 stabilizer fixing all four A1 nodes simultaneously. In the chiral two-form bases, omega_1^+ and omega_1^- are invariant and are exactly the rank-one R^\pm eigenlines, while K^+ = (omega_1^+)^\perp has weight alpha+beta and K^- = (omega_1^-)^\perp has weight alpha-beta. The beta=0 subcircle acts with ordinary weight one on every kernel plane. A homogeneous quadratic local map K_j -> K_j would require a monomial z^a \bar z^b with a+b=2 and a-b=1 under this subcircle, which is impossible. This repairs Gate 1 without relying on the invalid SO(2) sentence and also identifies the genuine structural content: rank-one bi-Kaehler curvature gives a two-dimensional kernel, so after an EH parameter zeta consumes one kernel direction the complementary block still contains another kernel direction. A generic det R=0 orbifold with one-dimensional kernel would not have this protection; the second obstruction would normally bite.

The same T^2 audit gives a useful finite-dimensional selection rule before any Green function is evaluated. A pair term is linear in the receiver variable and quadratic in the source variable. With source weight w_i=(1,epsilon_i) and receiver weight w_j=(1,epsilon_j), the only T^2-balanced monomials of degree two in z_i,\bar z_i and degree one in z_j,\bar z_j with target weight w_j are |z_i|^2 z_j for every pair, and z_i^2 \bar z_j only when epsilon_i=epsilon_j. Thus opposite-chirality pair response is necessarily isotropic on the receiver kernel plane; there is no angular transversality question for an opposite pair by itself. Same-chirality pair response may have both isotropic and anisotropic components. This turns A01's observed SO(2)-isotropic odd receiver into a derived selection rule, not an unexplained numerical feature. For the diagonal balanced pattern each node sees two opposite-chirality adjacent neighbours and one same-chirality diagonal neighbour. Compared against the all-compatible pattern, the diagonal same-chirality term is common and cancels; the mixed-minus-compatible difference at equal scales and unit source norms is controlled by two adjacent coefficient differences. In notation, the reduced local pair target is of the form 2(B_adj^opp - B_adj^same) on the isotropic part, with possible same-adjacent anisotropic subtraction only if the all-compatible identity does not separately kill it. This narrows Gate 3 from a four-node Green table to adjacent-pair coefficients plus the global coupling filter.

The r=0 all-compatible row must be used carefully. The strategist's stronger claim is that there is an exact curve of positive Kaehler--Einstein degree-4 del Pezzo metrics degenerating to the four-A1 product quotient, not merely that the smooth diffeotype CP^2#5\bar{CP}^2 admits some positive Einstein metric. I source-checked this during the step. Odaka--Spotti--Sun's JDG paper, newly retrieved/read as `Knowledge/objects/papers/COMPACT-MODULI-SPACES-OF-DEL-PEZZO-SURFACES--3cb2439eac00--b970fe5e4bdb/object.md`, gives the degree-four GH/GIT compactification, Theorem 4.1 GIT stability for intersections of two quadrics, Theorem 4.2 identification with KE moduli, and explicitly states that the unique degree-four surface with four A1 singularities is isomorphic to (P^1 x P^1)/(Z/2), admitting the quotient KE metric. This strongly supports the existence of smooth KE degree-four surfaces approaching that boundary point in moduli, but I did not have time to extract exact local deformation coordinates, smoothing scales, or an Ozuch-chart statement proving F_j(S0;t) vanishes order-by-order in the same finite-dimensional variables being used in our real Riemannian gluing expansion. Spotti's nodal KE deformation paper was also read and supplies an analytic smoothing theorem for nodal KE del Pezzo orbifolds with finite automorphism group, but the product four-A1 quotient has positive-dimensional automorphism, so it is not a direct substitute for the OSS moduli-continuity statement. Consequently, the r=0 row should be treated as a powerful calibration and likely exact baseline, but the next step must write the precise source-grounded version before using it to assert pairwise or order-by-order coefficient cancellation.

The global deformation coupling is now also better organized. T^2 symmetry filters it: only T^2-invariant orbifold deformation/kernel modes can be excited by a T^2-symmetric configuration, and the source-quadratic invariant is |z_i|^2. However, T^2 alone does not eliminate the four scalar Ozuch zero modes u_A g_A, u_A g_B, u_B g_A, u_B g_B, because axial pole harmonics are invariant under rotations about the pole axes. Existing A-symmetry, factor-tracelessness, and Bianchi-corrected local calculations from A01/A02 support leading scalar decoupling in the diagonal symmetric problem, but a full Ozuch-gauge Delta-nu calculation is still required. If the T^2-invariant part of Delta nu vanishes, the O(t^3) global coupling disappears in the symmetric sector and adjacent pair coefficients become the sole decider. If it survives, Gate 3 must include it at the same order as the pair response.

The high-dimensional Gromov half of Step 94 also needs a wording repair before any Lean formalization. The usable statement is: there is a dimensional constant C(n) with ||M|| <= C(n) Vol(M,g) whenever Ric_g >= -(n-1)g; if Ric_g >= 0, then for epsilon^2 g the Ricci lower bound remains compatible with the comparison while volume scales like epsilon^n, forcing ||M||=0. Step 94's displayed argument using a proportionality-principle-style expression was garbled. The conclusion that positive simplicial volume obstructs nonnegative Einstein metrics is correct, but the proof should be patched before becoming a formal arithmetic target.
