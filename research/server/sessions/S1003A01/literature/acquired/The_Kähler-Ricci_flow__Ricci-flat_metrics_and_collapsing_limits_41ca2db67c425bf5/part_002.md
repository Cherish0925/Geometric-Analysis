[Part 2/2 of: The Kähler-Ricci flow, Ricci-flat metrics and collapsing limits]

As in the proof of Theorem 2.1, one sees easily that $F$ is constant along the fibers $X_{y}, y \in B \backslash S^{\prime}$, so it descends to a smooth function $F$ on $B \backslash S^{\prime}$. Then [40, Section 3] shows that the Monge-Ampère equation
$$(\chi+\sqrt{-1} \partial \bar{\partial} v)^{m}=F e^{v} \chi^{m},$$
has a unique solution $v$ (in the sense of Bedford-Taylor [4]) which is a bounded $\chi$-plurisubharmonic function on $B$, smooth on $B \backslash S^{\prime}$. The $L^{\infty}$ bound for $v$ uses the pluripotential estimates of Kołodziej [24] (see also the survey [30]). We define
$$\omega_{B}:=\chi+\sqrt{-1} \partial \bar{\partial} v,$$
which is a smooth Kähler metric on $B \backslash S^{\prime}$, and satisfies the twisted Kähler-Einstein equation
$$\operatorname{Ric}\left(\omega_{B}\right)=-\omega_{B}+\omega_{\mathrm{WP}},$$
where $\omega_{\mathrm{WP}}$ is the smooth semipositive Weil-Petersson form on $B \backslash S^{\prime}$ constructed in Section 2.1. We also define
$$\Omega=\binom{n+m}{n} \omega_{\mathrm{SRF}}^{n} \wedge \omega_{B}^{m},$$
and using (3.1) and (3.2) we observe that
$$\Omega=\Omega_{1} \frac{\omega_{B}^{m}}{F \chi^{m}}=\Omega_{1} e^{v},$$
which is thus a bounded strictly positive volume form on $X$, smooth on $X \backslash S$. As in the proof of Theorem 2.1, we can see that
$$\sqrt{-1} \partial \bar{\partial} \log \Omega=\omega_{B},$$
holds on $X \backslash S$.
Let then $\omega=\omega(t)$ be a solution of the Kähler-Ricci flow
$$\frac{\partial}{\partial t} \omega=-\operatorname{Ric}(\omega)-\omega, \quad \omega(0)=\omega_{0},$$
which exists for all time. We gather together some facts about the Kähler-Ricci flow in this case which are already known, or which follow easily from the existing literature.

We begin by writing the flow as a parabolic complex Monge-Ampère equation. Since $\Omega$ is not smooth everywhere, it is more convenient to use the smooth volume form $\Omega_{1}$. Similarly, since the limiting metric $\omega_{B}$ is not smooth everywhere, we replace it by $\chi$ which is smooth on the whole of $X$.

We therefore define the reference metrics
$$\hat{\omega}=e^{-t} \omega_{0}+\left(1-e^{-t}\right) \chi,$$
which are Kähler for all $t \geqslant 0$, and for all $t \geqslant 0$ we can write $\omega=\hat{\omega}+$ $\sqrt{-1} \partial \bar{\partial} \varphi$, and $\varphi(0)=0$. Then the Kähler-Ricci flow is equivalent to the
parabolic complex Monge-Ampère equation
$$\frac{\partial}{\partial t} \varphi=\log \frac{e^{n t}(\hat{\omega}+\sqrt{-1} \partial \bar{\partial} \varphi)^{n+m}}{\Omega_{1}}-\varphi, \quad \varphi(0)=0, \quad \hat{\omega}+\sqrt{-1} \partial \bar{\partial} \varphi>0 .$$
It is convenient to introduce, following [54, Section 2], a smooth nonnegative function $\sigma$ on $X$ with zero locus exactly equal to $S$ and with
$$\sigma \leqslant 1, \quad \sqrt{-1} \partial \sigma \wedge \bar{\partial} \sigma \leqslant C \chi, \quad-C \chi \leqslant \sqrt{-1} \partial \bar{\partial} \sigma \leqslant C \chi,$$
for some constant $C$ (in the case when $S$ is empty, i.e. when $\pi$ is a submersion and $B$ nonsingular, we can set $\sigma=1$ ). Explicitly, let $\mathcal{I}$ be the ideal sheaf of $S^{\prime}$ inside $\mathbb{P} H^{0}\left(X, K_{X}^{\ell}\right)$, let $\left\{U_{j}\right\}$ be an open cover of $\mathbb{P} H^{0}\left(X, K_{X}^{\ell}\right)$ such that on each $U_{j}$ the ideal $\mathcal{I}$ is generated by finitely many holomorphic functions $\left\{f_{j, k}\right\}$, let $\rho_{j}$ be a partition of unity subordinate to this cover, and define a smooth function on $\mathbb{P} H^{0}\left(X, K_{X}^{\ell}\right)$ by
$$\sigma=C^{-1} \sum_{j, k} \rho_{j}\left|f_{j, k}\right|^{2},$$
where $C$ is a constant chosen so that $\sigma \leqslant 1$. Then the pullback of $\sigma$ to $X$ is the function that we need. We have the following lemma, which is an analogue of Lemma 2.2.

Lemma 3.1. Let $\omega=\omega(t)$ solve the Kähler-Ricci flow as above, and write $\varphi=\varphi(t)$ for the solution of (3.3). Then
\begin{itemize}
\item[(i)] For any compact set $K \subset X \backslash S$ there is a constant $C=C(K)$ such that $C^{-1} \hat{\omega} \leqslant \omega \leqslant C \hat{\omega}$ on $K$ for all $t \geqslant 0$.
\item[(ii)] There exists $\lambda>0$ and a positive decreasing function $h(t)$ which tends to zero as $t \rightarrow \infty$ such that
\end{itemize}
$$\sup _{X}\left|\sigma^{\lambda}(\varphi-v)\right| \leqslant h(t), \quad \text { for all } t \geqslant 0 .$$
\begin{itemize}
\item[(iii)] There exists $C$ such that $|R| \leqslant C$ on $X \times[0, \infty)$.
\item[(iv)] There exists $C$ such that, for $h, \lambda$ as in (ii),
\end{itemize}
$$\sup _{X}\left|\sigma^{\lambda}(\varphi+\dot{\varphi}-v)\right| \leqslant C h(t)^{\frac{1}{2}}, \quad \text { for all } t \geqslant 0 .$$
Proof. Part (i) is proved in [12] (and is a direct adaptation of [54], see also [39] for the case of elliptic surfaces). Part (ii) is due to Song-Tian (see the proof of [40, Proposition 5.4]). Note that we are free to increase the value of $\lambda$, at the expense of changing the function $h(t)$. Part (iii) was proved in [42].

The proof of (iv) is almost identical to the proof of Lemma 2.2. (iv). Indeed, it is enough to show that $\sup _{X}\left|\sigma^{\lambda} \dot{\varphi}\right| \leqslant C h(t)^{\frac{1}{2}}$. We have as before $\frac{\partial}{\partial t} \dot{\varphi}=-R-m-\dot{\varphi}$ and hence $|\dot{\varphi}|,|\partial \dot{\varphi} / \partial t| \leqslant C_{0}$ for some uniform constant $C_{0}$. Suppose for a contradiction that we do not have the desired upper
bound of $\sigma^{\lambda} \dot{\varphi}$. Then there exists a sequence $\left(x_{k}, t_{k}\right) \in X \times[0, \infty)$ with $t_{k} \rightarrow \infty$ as $k \rightarrow \infty$ such that
$$\sigma^{\lambda}\left(x_{k}\right) \dot{\varphi}\left(x_{k}, t_{k}\right) \geqslant k h\left(t_{k}\right)^{\frac{1}{2}} .$$
In particular, $x_{k} \notin S$. Put $\gamma_{k}=\frac{k}{2 C_{0} \sigma^{\lambda}\left(x_{k}\right)} h\left(t_{k}\right)^{\frac{1}{2}}$. At $x_{k}$ we have $\sigma^{\lambda} \dot{\varphi} \geqslant$ $\frac{k}{2} h\left(t_{k}\right)^{\frac{1}{2}}$ on $\left[t_{k}, t_{k}+\gamma_{k}\right]$. Then, using (3.6), we have at $x_{k}$,
$$\begin{aligned}
2 h\left(t_{k}\right) \geqslant\left(h\left(t_{k}+\gamma_{k}\right)+h\left(t_{k}\right)\right) & \geqslant \sigma^{\lambda} \int_{t_{k}}^{t_{k}+\gamma_{k}} \dot{\varphi} d t \\
& \geqslant \gamma_{k} \frac{k}{2} h\left(t_{k}\right)^{\frac{1}{2}}=\frac{k^{2}}{4 C_{0} \sigma^{\lambda}} h\left(t_{k}\right),
\end{aligned}$$
which gives a contradiction when $k \rightarrow \infty$ and we are done. The lower bound is similar. \(\square\)

The next lemma follows from a straightforward computation.
Lemma 3.2. Along the Kähler-Ricci flow, we have on $X \backslash S$,
$$\left(\frac{\partial}{\partial t}-\Delta\right)(\varphi+\dot{\varphi}-v)=\operatorname{tr}_{\omega} \omega_{B}-m .$$
Proof. This follows from the evolution equations
$$\begin{aligned}
& \left(\frac{\partial}{\partial t}-\Delta\right) \varphi=\dot{\varphi}-(n+m)+\operatorname{tr}_{\omega} \hat{\omega}, \\
& \left(\frac{\partial}{\partial t}-\Delta\right) \dot{\varphi}=\operatorname{tr}_{\omega}(\chi-\hat{\omega})+n-\dot{\varphi},
\end{aligned}$$
and the equation $\Delta v=\operatorname{tr}_{\omega}\left(\omega_{B}-\chi\right)$. \(\square\)

Next, from [39, 40, 42], we have:
Lemma 3.3. There exist positive constants $C, C^{\prime}$ and $\lambda$ such that
$$\chi \leqslant C \omega, \quad \omega_{B} \leqslant C \sigma^{-\lambda} \chi, \quad \omega_{B} \leqslant C \sigma^{-\lambda} \omega,$$
wherever these quantities are defined, and
$$|\nabla \sigma|^{2} \leqslant C, \quad|\Delta \sigma| \leqslant C .$$
On $X \backslash S$ we have
$$\left(\frac{\partial}{\partial t}-\Delta\right) \operatorname{tr}_{\omega} \omega_{B} \leqslant \operatorname{tr}_{\omega} \omega_{B}+C \sigma^{-\lambda}\left(\operatorname{tr}_{\omega} \omega_{B}\right)^{2} \leqslant C^{\prime} \sigma^{-3 \lambda} .$$
Proof. The first inequality of (3.9) is given in [42, Proposition 2.2]. The second is a consequence of the arguments in [40, Theorem 3.3], as follows: Song-Tian construct the metric $\omega_{B}$ by working on a resolution $\mu: Y \rightarrow B$ so that $\mu^{-1}\left(S^{\prime}\right)$ is a simple normal crossing divisor $E$. The class $\left[\mu^{*} \chi\right]$ is semipositive and big, and since $\mu^{*} \chi=\frac{1}{\ell} \tilde{\mu}^{*} \omega_{\mathrm{FS}}$, where $\tilde{\mu}$ is the composition $Y \rightarrow B \rightarrow \mathbb{P} H^{0}\left(X, K_{X}^{\ell}\right)$, a standard argument shows that $\left[\mu^{*} \chi\right]-\varepsilon[E]$
contains a Kähler metric $\omega_{Y}$, for some $\varepsilon>0$. Then the results of [9] give a bounded solution $\hat{v}$ of the Monge-Ampère equation
$$\left(\mu^{*} \chi+\sqrt{-1} \partial \bar{\partial} \hat{v}\right)^{m}=\left(\mu^{*} F\right) e^{\hat{v}}\left(\mu^{*} \chi\right)^{m}, \quad \mu^{*} \chi+\sqrt{-1} \partial \bar{\partial} \hat{v}>0,$$
which is smooth away from $E$. If we let $\hat{\omega}_{B}=\mu^{*} \chi+\sqrt{-1} \partial \bar{\partial} \hat{v}$, then $\hat{\omega}_{B}$ descends to the metric $\omega_{B}$ on $B \backslash S^{\prime}$. Then [40, Theorem 3.3] gives
$$\hat{\omega}_{B} \leqslant C\left|s_{E}\right|_{h_{E}}^{-\alpha} \omega_{Y},$$
for some $\alpha>0$, where $s_{E}$ is a defining section of the line bundle associated to $E$ and $h_{E}$ is a smooth metric on it. From the construction of $\sigma$ in (3.5), it follows that $\mu^{*} \sigma$ is bounded above by $\left|s_{E}\right|_{h_{E}}^{\beta}$ for some $\beta>0$. Since $\mu: Y \backslash E \rightarrow B \backslash S^{\prime}$ is an isomorphism, the metric $\omega_{Y}$ induces a metric $\omega_{Y}^{\prime}$ on $B \backslash S^{\prime}$ and we have
$$\omega_{B} \leqslant C \sigma^{-\gamma} \omega_{Y}^{\prime},$$
for some $\gamma>0$. But on $Y$ we also have
$$\omega_{Y} \leqslant C\left|s_{E}\right|_{h_{E}}^{-\delta} \mu^{*} \chi,$$
for some $\delta>0$, since the subvariety of $Y$ where $\tilde{\mu}$ fails to be an immersion is contained in $E$. On $B \backslash S^{\prime}$ this implies that
$$\omega_{Y}^{\prime} \leqslant C \sigma^{-\gamma^{\prime}} \chi,$$
for some $\gamma^{\prime}>0$. Combining (3.13) and (3.14) we obtain the second inequality of (3.9). The third is obtained by combining the first and second inequalities. The inequalities (3.10) follow from (3.4) and the inequality $\chi \leqslant C \omega$.

Local higher order estimates for the equation (3.2) imply that the bisectional curvature of $\omega_{B}$ is bounded by $C \sigma^{-\lambda}$ on $B \backslash S^{\prime}$, up to increasing $\lambda$. The Schwarz Lemma calculation [39, Section 4] (see also the exposition in [45, Theorem 3.2.6]) then gives the first inequality (3.11), and the second follows from (3.9). \(\square\)
3.2. Collapsing estimates for the Kähler-Ricci flow away from the singular set. We now give the proof of Theorem 1.2. First, we have an analogue of Lemma 2.8. It is more complicated in this case because of the singular set, and the fact that the quantity $\sigma^{\lambda}(\varphi+\dot{\varphi}-v)$, which now takes the role of $\varphi+\dot{\varphi}$, does not decay exponentially.

Lemma 3.4. Given a compact set $K \subset X \backslash S$, there is a positive decreasing function $F(t)$ which goes to zero as $t \rightarrow \infty$ such that
$$\sup _{K}\left(\operatorname{tr}_{\omega} \omega_{B}-m\right) \leqslant F(t) .$$

Proof. Let $h(t)$ be a positive decreasing function which goes to zero as $t \rightarrow \infty$ such that
$$\sup _{X}\left|\sigma^{\lambda}(\varphi+\dot{\varphi}-v)\right| \leqslant h(t),$$
which exists thanks to (3.7). We may assume without loss of generality that $h^{\prime}(t) \rightarrow 0$ as $t \rightarrow \infty$. Indeed, by assumption there exists a sequence $t_{i} \rightarrow \infty$ with $h(t) \leqslant \frac{1}{i}$ for all $t \geqslant t_{i}$, and $t_{i+1}-t_{i} \geqslant 1$. Define a piecewise constant function $\tilde{h}(t), t \geqslant 0$, to be equal to $\frac{1}{i}$ on the interval $t_{i} \leqslant t<t_{i+1}$, so clearly $h(t) \leqslant \tilde{h}(t)$ for all $t \geqslant t_{1}$. We can then smooth out $\tilde{h}$ in the obvious way (making it continuous and essentially linear on each interval $t_{i} \leqslant t<t_{i+1}$ ) to obtain a smooth nonnegative and decreasing function $\hat{h}(t)$ with $\tilde{h}(t) \leqslant \hat{h}(t)$ for all $t \geqslant 0$ and so that $\hat{h}(t)$ still goes to zero and the derivative of $\hat{h}(t)$ on the interval $t_{i} \leqslant t<t_{i+1}$ is of the order of $\left(i\left(t_{i+1}-t_{i}\right)\right)^{-1}$ which goes to zero. We then replace $h(t)$ by $\hat{h}(t)$ (still calling it $h(t)$ ).

Next, we pick a smooth positive function $\ell(t), t \geqslant 0$, with $\lim _{t \rightarrow \infty} \ell(t)=$ $\infty$, such that $\left|\ell^{\prime}(t)\right| \leqslant C$ for all $t \geqslant 0$ and
$$\ell(t) \leqslant \frac{1}{h(t)^{\frac{1}{2}}}, \quad \ell(t) \leqslant-\frac{1}{h^{\prime}(t)} .$$
Define
$$Q=\ell(t) \sigma^{3 \lambda}\left(\operatorname{tr}_{\omega} \omega_{B}-m\right)-\frac{1}{h(t)} \sigma^{3 \lambda}(\varphi+\dot{\varphi}-v) .$$
Then using Lemmas 3.2, 3.3 and (3.15), we have on $X \backslash S$,
$$\begin{aligned}
& \left(\frac{\partial}{\partial t}-\Delta\right) Q \\
& \leqslant\left(\ell^{\prime}(t)-\frac{1}{h(t)}\right) \sigma^{3 \lambda}\left(\operatorname{tr}_{\omega} \omega_{B}-m\right)+C(\ell(t)+1)+\frac{h^{\prime}(t)}{h(t)^{2}} \sigma^{3 \lambda}(\varphi+\dot{\varphi}-v) \\
& -2 \operatorname{Re}\left\langle\nabla\left(\sigma^{3 \lambda}\right), \nabla\left(\ell(t)\left(\operatorname{tr}_{\omega} \omega_{B}-m\right)-\frac{1}{h(t)}(\varphi+\dot{\varphi}-v)\right)\right\rangle \\
& \leqslant\left(\ell^{\prime}(t)-\frac{1}{h(t)}\right) \sigma^{3 \lambda}\left(\operatorname{tr}_{\omega} \omega_{B}-m\right)+C(\ell(t)+1)-\frac{h^{\prime}(t)}{h(t)} \\
& -2 \sigma^{-3 \lambda} \operatorname{Re}\left\langle\nabla\left(\sigma^{3 \lambda}\right), \nabla Q\right\rangle+C Q \sigma^{-2},
\end{aligned}$$
where we have used the fact that $\left|\Delta\left(\sigma^{3 \lambda}\right)\right| \leqslant C \sigma^{\lambda}$. Observe that from (3.9) and (3.15) we have $\sigma^{-2} Q \leqslant C \ell(t)$, since we may assume that $\lambda \geqslant 1$. Since $\left|\ell^{\prime}(t)\right| \leqslant C$, we may assume that $t$ is sufficiently large so that
$$\ell^{\prime}(t) \leqslant \frac{1}{2 h(t)} .$$
We wish to obtain an upper bound for $Q$ using the maximum principle. Hence we may assume without loss of generality that we are working at a point with $\operatorname{tr}_{\omega} \omega_{B}-m>0$. Therefore we get
$$\begin{aligned}
\left(\frac{\partial}{\partial t}-\Delta\right) Q \leqslant & -\frac{1}{2 h(t)} \sigma^{3 \lambda}\left(\operatorname{tr}_{\omega} \omega_{B}-m\right)+C(\ell(t)+1)-\frac{h^{\prime}(t)}{h(t)} \\
& -2 \sigma^{-3 \lambda} \operatorname{Re}\left\langle\nabla\left(\sigma^{3 \lambda}\right), \nabla Q\right\rangle,
\end{aligned}$$
and so at a maximum point of $Q$ (which is necessarily in $X \backslash S$ ) we have
$$Q \leqslant C \ell(t)(\ell(t)+1) h(t)-2 \ell(t) h^{\prime}(t)+C \leqslant C,$$
thanks to our choice of $\ell(t)$. This proves what we want, choosing $F(t)=\frac{C}{\ell(t)}$, for $C$ depending on the compact set $K$. \(\square\)

The rest of the proof of Theorem 1.2 is almost identical to the proof of Theorem 1.1.

Proof of Theorem 1.2. To avoid repetition, we provide here just an outline of the proof, emphasizing the changes from the proof of Theorem 1.1.

For the rest of the proof, fix a compact set $K^{\prime} \subset B \backslash S^{\prime}$ and write $K=$ $\pi^{-1}\left(K^{\prime}\right) \subset X \backslash S$.

First, there exists a constant $C$ such that
$$\left\|\left.e^{t} \omega\right|_{X_{y}}\right\|_{C^{1}\left(X_{y},\left.\omega_{0}\right|_{X_{y}}\right)} \leqslant C,\left.\quad e^{t} \omega\right|_{X_{y}} \geqslant\left. C^{-1} \omega_{0}\right|_{X_{y}},$$
for all $t \geqslant 0$ and for all $y \in K^{\prime}$. Indeed, this follows from the same argument as in Lemma 2.9, since $\pi$ is a submersion near every point in $\pi^{-1}\left(K^{\prime}\right)$.

In particular, for any fixed $y \in B \backslash S^{\prime}$ and $0<\alpha<1$, given any sequence $t_{k} \rightarrow \infty$ we can extract a subsequence such that
$$\left.e^{t_{k}} \omega\right|_{X_{y}} \rightarrow \omega_{\infty, y}, \quad \text { in } C^{\alpha} \text { on } X_{y},$$
where $\omega_{\infty, y}$ is a $C^{\alpha}$ Kähler metric on $X_{y}$ cohomologous to $\left.\omega_{0}\right|_{X_{y}}$.
Next we claim that we have fiberwise $C^{\alpha}$ convergence of $\left.e^{t} \omega\right|_{X_{y}}$ to $\omega_{\text {SRF }, y}$ for $y \in K^{\prime}$. More precisely, given $\alpha \in(0,1)$ and $y \in K^{\prime}$, we have that
$$\left.e^{t} \omega\right|_{X_{y}} \rightarrow \omega_{\text {SRF }, y}, \quad \text { in } C^{\alpha} \text { as } t \rightarrow \infty \text { on } X_{y} .$$
Indeed, on $X \backslash S$ write
$$f=e^{\varphi+\dot{\varphi}-v}\binom{n+m}{n} \frac{\omega^{n} \wedge \omega_{B}^{m}}{\omega^{n+m}},$$
so that restricted to $X_{y}\left(y \in K^{\prime}\right)$ we have $\left(\left.e^{t} \omega\right|_{X_{y}}\right)^{n}=f\left(\omega_{\text {SRF }, y}\right)^{n}$. Note that
$$\int_{X_{y}}(f-1)\left(\omega_{\mathrm{SRF}, y}\right)^{n}=0,$$
and, thanks to (3.7),
$$\sup _{K}\left|e^{\varphi+\dot{\varphi}-v}-1\right| \rightarrow 0, \quad \text { as } t \rightarrow \infty .$$
Moreover, as in (2.19) and using Lemma 3.4, on $K$ we have
$$\binom{n+m}{n} \frac{\omega^{n} \wedge \omega_{B}^{m}}{\omega^{n+m}} \leqslant\left(\operatorname{tr}_{\omega} \omega_{B} / m\right)^{m} \leqslant 1+H(t),$$
for $H(t) \rightarrow 0$ as $t \rightarrow \infty$. Hence $f-1 \leqslant h(t)$, with $h(t) \rightarrow 0$ as $t \rightarrow \infty$. Finally, $f$ satisfies $\left|\nabla\left(\left.f\right|_{X_{y}}\right)\right|_{\left.\omega_{0}\right|_{X_{y}}} \leqslant A$ for all $y \in K^{\prime}$. Applying Lemma 2.4
to $f-1$ on $K$ (see Remark 2.5) we have that $f$ converges to 1 uniformly on $K$. Namely,
$$\left\|\left(\left.e^{t} \omega\right|_{X_{y}}\right)^{n}-\omega_{\mathrm{SRF}, y}^{n}\right\|_{C^{0}\left(X_{y},\left.\omega_{0}\right|_{X_{y}}\right)} \rightarrow 0, \quad \text { as } t \rightarrow \infty,$$
uniformly as $y$ varies in $K^{\prime}$. In particular, $\left.e^{t} \omega\right|_{X_{y}} \rightarrow \omega_{\text {SRF }, y}$ in $C^{\alpha}$ by (3.16) and the same argument as in Lemma 2.10.

Next we show that
$$\left\|\left.e^{t} \omega\right|_{X_{y}}-\omega_{\mathrm{SRF}, y}\right\|_{C^{0}\left(X_{y}, \omega_{0} \mid X_{y}\right)} \rightarrow 0, \quad \text { as } t \rightarrow \infty,$$
uniformly for $y \in K^{\prime}$. To see this, define
$$f=e^{\varphi+\dot{\varphi}-v}\binom{n+m}{n} \frac{\omega \wedge\left(e^{-t} \omega_{\mathrm{SRF}}\right)^{n-1} \wedge \omega_{B}^{m}}{\omega^{n+m}},$$
which satisfies
$$\left.f\right|_{X_{y}}=\frac{\left(\left.e^{t} \omega\right|_{X_{y}}\right) \wedge \omega_{\mathrm{SRF}, y}^{n-1}}{\omega_{\mathrm{SRF}, y}^{n}},$$
when restricted to $X_{y}$, for $y \in K^{\prime}$. By the same argument as in the proof of (1.6) in Section 2, we see that $f$ converges 1 as $t \rightarrow 0$ and hence
$$\left\|\left(\left.e^{t} \omega\right|_{X_{y}}\right) \wedge \omega_{\mathrm{SRF}, y}^{n-1}-\omega_{\mathrm{SRF}, y}^{n}\right\|_{C^{0}\left(X_{y},\left.\omega_{0}\right|_{X_{y}}\right)} \rightarrow 0, \quad \text { as } t \rightarrow \infty,$$
uniformly as $y$ varies in $K^{\prime}$. From (3.18) and (3.20), we apply Lemma 2.6 to obtain (3.19) as required.

It remains to prove part (i) of Theorem 1.2. Define
$$\tilde{\omega}=e^{-t} \omega_{\mathrm{SRF}}+\left(1-e^{-t}\right) \omega_{B},$$
as in Section 2. On $K$ we have
$$\operatorname{tr}_{\omega} \tilde{\omega}=\operatorname{tr}_{\omega} \omega_{B}+\operatorname{tr}_{\omega}\left(e^{-t} \omega_{\mathrm{SRF}, y}\right)+e^{-t}\left(-\operatorname{tr}_{\omega} \omega_{B}+\operatorname{tr}_{\omega}\left(\omega_{\mathrm{SRF}}-\omega_{\mathrm{SRF}, y}\right)\right) .$$
On $K, \operatorname{tr}_{\omega} \omega_{B}$ is uniformly bounded. It then follows by the same argument as in the proof of (2.23) that
$$\sup _{K}\left|e^{-t}\left(-\operatorname{tr}_{\omega} \omega_{B}+\operatorname{tr}_{\omega}\left(\omega_{\text {SRF }}-\omega_{\text {SRF }, y}\right)\right)\right| \leqslant C e^{-t / 2} .$$
Moreover, (3.19) implies that $\operatorname{tr}_{\omega}\left(e^{-t} \omega_{\text {SRF }, y}\right) \leqslant n+h(t)$ for $h(t) \rightarrow 0$, on $K$. Then from Lemma 3.4 we have on $K$, after possibly changing $h(t)$,
$$\operatorname{tr}_{\omega} \tilde{\omega}-(n+m) \leqslant h(t) \rightarrow 0 .$$
On the other hand, again on $K$,
$$\frac{\tilde{\omega}^{n+m}}{\omega^{n+m}}=\binom{n+m}{n} \frac{e^{-n t} \omega_{\mathrm{SRF}}^{n} \wedge \omega_{B}^{m}}{\omega^{n+m}}+O\left(e^{-t}\right)=e^{-\varphi-\dot{\varphi}+v}+O\left(e^{-t}\right) \rightarrow 1 .$$
Applying Lemma 2.6, we obtain
$$\|\omega-\tilde{\omega}\|_{C^{0}(K, \omega)} \rightarrow 0, \quad \text { as } t \rightarrow \infty .$$
But since $\omega \leqslant C \omega_{0}$ on $K$, and $\tilde{\omega}=\omega_{B}+e^{-t}\left(\omega_{\text {SRF }}-\omega_{B}\right)$ we obtain
$$\left\|\omega-\omega_{B}\right\|_{C^{0}\left(K, \omega_{0}\right)} \rightarrow 0, \quad \text { as } t \rightarrow \infty,$$
as required. \(\square\)

\section*{4. Collapsing of Ricci-flat Kähler metrics}

In this section we prove Theorem 1.3.
4.1. Monge-Ampère equations and preliminary estimates. Let $\left(X, \omega_{X}\right)$ be a compact $(n+m)$ manifold with a Ricci-flat Kähler metric $\omega_{X}$, as in Section 1.3 of the Introduction. Recall that we have a holomorphic map $\pi:\left(X, \omega_{X}\right) \rightarrow\left(Z, \omega_{Z}\right)$ between compact Kähler manifolds with (possibly singular) image $B$, a normal variety in $Z$. We denote by $S^{\prime} \subset B$ those points of $B$ which are either singular in $B$ or critical for $\pi$, and we write $S=\pi^{-1}\left(S^{\prime}\right)$. The fibers $X_{y}$ for $y \in B \backslash S^{\prime}$ are Calabi-Yau $n$-folds.

Write $\chi=\pi^{*} \omega_{Z}$, which is a smooth nonnegative $(1,1)$ form on $X$, and we will also write $\chi$ for the restriction of $\omega_{Z}$ to $B \backslash S^{\prime}$. Note that $\int_{B \backslash S^{\prime}} \chi^{m}$ is finite.

We define a semi Ricci-flat form $\omega_{\mathrm{SRF}}$ on $X \backslash S$ in the same way as in Section 2.1. Indeed, for each $y \in B \backslash S^{\prime}$ there is a smooth function $\rho_{y}$ on $X_{y}$ so that $\left.\omega_{X}\right|_{X_{y}}+\sqrt{-1} \partial \bar{\partial} \rho_{y}=\omega_{\text {SRF,y }}$ is Ricci-flat, normalized by $\int_{X_{y}} \rho_{y}\left(\omega_{X} \mid X_{y}\right)^{n}=0$. As $y$ varies, this defines a smooth function $\rho$ on $X \backslash S$ and we define $\omega_{\mathrm{SRF}}=\omega_{X}+\sqrt{-1} \partial \bar{\partial} \rho$.

Let $F$ be the function on $X \backslash S$ given by
$$F=\frac{\omega_{X}^{n+m}}{\binom{n+m}{n} \omega_{\mathrm{SRF}}^{n} \wedge \chi^{m}} .$$
As in the proof of Theorem 2.1, one sees easily that $F$ is constant along the fibers $X_{y}, y \in B \backslash S^{\prime}$, so it descends to a smooth function $F$ on $B \backslash S^{\prime}$. We see that $F$ satisfies $\int_{B \backslash S^{\prime}} F \chi^{m}=\int_{X} \omega_{X}^{n+m} /\binom{n+m}{n} \int_{X_{y}} \omega_{X}^{n}$ (see [40, Section 3] and [54, Section 4]). Here note that $\int_{X_{y}} \omega_{X}^{n}$ is independent of $y \in B \backslash S^{\prime}$.

Then [40, Section 3] shows that the Monge-Ampère equation
$$(\chi+\sqrt{-1} \partial \bar{\partial} v)^{m}=\frac{\binom{n+m}{n} \int_{X} \omega_{X}^{n} \wedge \chi^{m}}{\int_{X} \omega_{X}^{n+m}} F \chi^{m},$$
has a unique solution $v$ (in the sense of Bedford-Taylor [4]) which is a bounded $\chi$-plurisubharmonic function on $B$, smooth on $B \backslash S^{\prime}$, with $\int_{X} v \omega_{X}^{n+m}=$ 0, where here and henceforth we write $v$ for $\pi^{*} v$.

We define
$$\omega_{B}=\chi+\sqrt{-1} \partial \bar{\partial} v,$$
for $v$ solving (4.1). Note that we have
$$\omega_{\mathrm{SRF}}^{n} \wedge \omega_{B}^{m}=\frac{\binom{n+m}{n} \int_{X} \omega_{X}^{n} \wedge \chi^{m}}{\int_{X} \omega_{X}^{n+m}} F \omega_{\mathrm{SRF}}^{n} \wedge \chi^{m}=\frac{\int_{X} \omega_{X}^{n} \wedge \chi^{m}}{\int_{X} \omega_{X}^{n+m}} \omega_{X}^{n+m} .$$
Moreover, $\omega_{B}$ is a smooth Kähler metric on $B \backslash S^{\prime}$, and satisfies
$$\operatorname{Ric}\left(\omega_{B}\right)=\omega_{\mathrm{WP}},$$
where $\omega_{\mathrm{WP}}$ is a smooth semipositive form on $B \backslash S^{\prime}$ constructed in the same way as in Section 2.1.

As in Section 3.1, we fix a smooth nonnegative function $\sigma$ on $X$ with zero locus exactly equal to $S$ and with
$$\sigma \leqslant 1, \quad \sqrt{-1} \partial \sigma \wedge \bar{\partial} \sigma \leqslant C \chi, \quad-C \chi \leqslant \sqrt{-1} \partial \bar{\partial} \sigma \leqslant C \chi,$$
for some constant $C$ (in the case when $S$ is empty we set $\sigma=1$ ). It is convenient to define another smooth nonnegative function $\mathcal{F}$ with zero locus equal to $S$ by
$$\mathcal{F}=e^{-e^{A \sigma^{-\lambda}}},$$
for positive constants $A$ and $\lambda$ to be determined.
For $t \geqslant 0$, let $\tilde{\omega}=\tilde{\omega}(t)$, given by
$$\tilde{\omega}=\chi+e^{-t} \omega_{X} \in \alpha_{t}=[\chi]+e^{-t}\left[\omega_{X}\right],$$
be a family of reference Kähler metrics, and let $\omega=\tilde{\omega}+\sqrt{-1} \partial \bar{\partial} \varphi$ be the unique Ricci-flat Kähler metric on $X$ cohomologous to $\tilde{\omega}$, with the normalization $\int_{X} \varphi \omega_{X}^{n+m}=0$. Then $\omega$ solves the Calabi-Yau equation
$$\omega^{n+m}=c_{t} e^{-n t} \omega_{X}^{n+m},$$
where $c_{t}$ is the constant given by
$$c_{t}=\frac{\int_{X} e^{n t} \tilde{\omega}^{n+m}}{\int_{X} \omega_{X}^{n+m}}=\frac{1}{\int_{X} \omega_{X}^{n+m}} \sum_{k=0}^{m}\binom{n+m}{k} e^{-(m-k) t} \int_{X} \omega_{X}^{n+m-k} \wedge \chi^{k},$$
so
$$c_{t}=\binom{n+m}{n} \frac{\int_{X} \omega_{X}^{n} \wedge \chi^{m}}{\int_{X} \omega_{X}^{n+m}}+O\left(e^{-t}\right) .$$

The following estimates are already known by the work of the first-named author [54].

Lemma 4.1. Let $\omega=\omega(t)$ and $\varphi=\varphi(t)$ be as above. Then
(i) There exist positive constants $C, A, \lambda$ such that for $\mathcal{F}$ given by (4.4),
$$C^{-1} \mathcal{F} \tilde{\omega} \leqslant \omega \leqslant C \mathcal{F}^{-1} \tilde{\omega}, \quad \text { for all } t \geqslant 0 .$$
(ii) There exists $C$ such that $\sup _{X}|\varphi| \leqslant C$ for all $t \geqslant 0$.
(iii) $\int_{X}|\varphi-v| \omega_{X}^{n+m} \rightarrow 0$ as $t \rightarrow \infty$.
(iv) For any $\alpha \in(0,1)$, we have $\varphi \rightarrow v$ in $C_{\text {loc }}^{1, \alpha}(X \backslash S)$ as $t \rightarrow \infty$.

Proof. Part (i) is proved in [54] (see also [18, Lemma 4.1]). For part (ii), see [54, Theorem 2.1]. Parts (iii) and (iv) are proved in [54, Theorem 4.1]. \(\square\)

The estimate (4.8) is the reason why here and in the rest of this section we consider the function $\mathcal{F}$ instead of the simpler $\sigma^{-\lambda}$ which we used in the case of the Kähler-Ricci flow. We do not expect this to be optimal.

The next lemma is analogous to Lemma 3.3 above.

Lemma 4.2. There exist positive constants $C, C^{\prime}$ and $\lambda$ such that
$$\chi \leqslant C \omega, \quad \omega_{B} \leqslant C \sigma^{-\lambda} \chi, \quad \omega_{B} \leqslant C \sigma^{-\lambda} \omega,$$
wherever these quantities are defined, and
$$|\nabla \sigma|^{2} \leqslant C, \quad|\Delta \sigma| \leqslant C .$$
On $X \backslash S$ we have
$$\Delta \operatorname{tr}_{\omega} \omega_{B} \geqslant-\operatorname{tr}_{\omega} \omega_{B}-C \sigma^{-\lambda}\left(\operatorname{tr}_{\omega} \omega_{B}\right)^{2} \geqslant-C^{\prime} \sigma^{-3 \lambda} .$$

Proof. The proof is almost the same as that of Lemma 3.3. The first inequality of (4.9) is given by the Schwarz Lemma [54, Lemma 3.1]. The second follows again from the arguments in [40, Theorem 3.3], as in Lemma 3.3 (the fact that now $B$ is not necessarily projective does not affect the arguments), and the third follows immediately. The inequalities (4.10) then follow from (4.3).

Local higher order estimates for the equation (4.1) imply that the bisectional curvature of $\omega_{B}$ is bounded by $C \sigma^{-\lambda}$ on $B \backslash S^{\prime}$, up to increasing $\lambda$. The Schwarz Lemma calculation [54, Lemma 3.1] gives the first inequality (4.11), and the second follows from (4.9). \(\square\)
4.2. Collapsing estimates for Ricci-flat metrics. In this section, we give the proof of Theorem 1.3. Recall that the function $\mathcal{F}$ is given by (4.4) and depends on the two constants $A$ and $\lambda$.

Lemma 4.3. There are constants $A, \lambda>0$ and a positive function $h(t) \rightarrow 0$ as $t \rightarrow \infty$, such that
$$\sup _{X} \mathcal{F}|\varphi-v| \leqslant h(t) .$$
Proof. We choose $A, \lambda$ as in Lemma 4.1.(1). Taking the trace with respect to $g_{X}$ of $\omega=\tilde{\omega}+\sqrt{-1} \partial \bar{\partial} \varphi$ and applying Lemma 4.1(i), we have
$$\sup _{X} \mathcal{F}\left|\Delta_{g_{X}} \varphi\right| \leqslant C .$$
From Lemma 4.1.(ii) and the fact that $v$ is bounded we have
$$\sup _{X}|\varphi|+\sup _{X}|v| \leqslant C .$$
It follows that
$$\sup _{X} \mathcal{F}|\partial \varphi|_{g_{X}} \leqslant C,$$
from a rather standard interpolation type argument. Indeed, note that the Sobolev imbedding theorem and the $L^{p}$ elliptic estimates give for $p>$ $2(n+m)$,
$$\sup _{X}|\partial(\mathcal{F} \varphi)|_{g_{X}} \leqslant C\left(\left(\int_{X}\left|\Delta_{g_{X}}(\mathcal{F} \varphi)\right|^{p}\right)^{1 / p}+\left(\int_{X}|\mathcal{F} \varphi|^{p}\right)^{1 / p}\right),$$
where we are integrating with respect to the volume form of $g_{X}$. Using (4.13), (4.14) and the Cauchy-Schwarz inequality, we obtain
$$\begin{aligned}
\sup _{X} \mathcal{F}|\partial \varphi|_{g_{X}} & \leqslant C\left(\left(\int_{X}\left(|\partial \varphi|_{g_{X}}|\partial \mathcal{F}|_{g_{X}}\right)^{p}\right)^{1 / p}+1\right) \\
& \leqslant C\left(\sup _{X}\left(\mathcal{F}|\partial \varphi|_{g_{X}}\right)^{(p-2) / p}\left(\int_{X}|\partial \varphi|_{g_{X}}^{2} \hat{\mathcal{F}}\right)^{1 / p}+1\right),
\end{aligned}$$
where $\hat{\mathcal{F}}=|\partial \mathcal{F}|_{g_{X}}^{p} / \mathcal{F}^{p-2}$. From the definition of $\mathcal{F}$ we see that $\hat{\mathcal{F}}+|\partial \hat{\mathcal{F}}|_{g_{X}} \leqslant$ $C \mathcal{F}$ and hence, integrating by parts,
$$\begin{aligned}
\int_{X}|\partial \varphi|_{g_{X}}^{2} \hat{\mathcal{F}} & =-\int_{X}\left(\varphi\left(\Delta_{g_{X}} \varphi\right) \hat{\mathcal{F}}-\varphi\langle\partial \varphi, \partial \hat{\mathcal{F}}\rangle_{g_{X}}\right) \\
& \leqslant C\left(\sup _{X} \mathcal{F}|\partial \varphi|_{g_{X}}+1\right) .
\end{aligned}$$
Then (4.15) follows from (4.16) and (4.17).
Next, the estimates in [40, Section 3], together with a similar argument give
$$\sup _{X} \mathcal{F}|\partial v|_{g_{X}} \leqslant C .$$

Combining (4.14), (4.15) and (4.18), we obtain
$$\sup _{X}|\partial(\mathcal{F}(\varphi-v))|_{g_{X}} \leqslant C .$$
From Lemma 4.1. (iii),
$$\int_{X} \mathcal{F}|\varphi-v| \omega_{X}^{n+m} \leqslant C \int_{X}|\varphi-v| \omega_{X}^{n+m} \rightarrow 0, \quad \text { as } t \rightarrow \infty,$$
and (4.12) now follows from (4.19) and (4.20). \(\square\)

Write $\dot{\varphi}$ and $\ddot{\varphi}$ for the first and second $t$-derivatives of $\varphi$. Then:
Lemma 4.4. There is a uniform constant $C$ so that
$$\sup _{X}|\dot{\varphi}| \leqslant C,$$
and
$$\sup _{X} \ddot{\varphi} \leqslant C .$$
Proof. First, we have
$$\Delta \varphi=n+m-\operatorname{tr}_{\omega} \tilde{\omega} .$$
Differentiating the logarithm of (4.5) with respect to $t$, we obtain
$$\left(\log c_{t}\right)^{\prime}-n=\operatorname{tr}_{\omega}(\sqrt{-1} \partial \bar{\partial} \dot{\varphi}+\chi-\tilde{\omega}),$$
and so
$$\Delta \dot{\varphi}=-n+\left(\log c_{t}\right)^{\prime}+\operatorname{tr}_{\omega} \tilde{\omega}-\operatorname{tr}_{\omega} \chi .$$

Hence
$$\Delta(\varphi+\dot{\varphi})=m-\operatorname{tr}_{\omega} \chi+\left(\log c_{t}\right)^{\prime} .$$
We have that $\left(\log c_{t}\right)^{\prime}=O\left(e^{-t}\right)$, because thanks to (4.6) we can write
$$\log c_{t}=\log \left(1+\sum_{k=1}^{m} a_{k} e^{-k t}\right)+\mathrm{const},$$
for some positive constants $a_{k}$, and the claim follows from differentiating this expression. Taking one more derivative, we also see that $\left(\log c_{t}\right)^{\prime \prime}=O\left(e^{-t}\right)$.

From the Schwarz Lemma (4.9) we have $\sup _{X} \operatorname{tr}_{\omega} \chi \leqslant C$, and hence $\mid \Delta(\varphi+$ $\dot{\varphi}) \mid \leqslant C$. The normalization for $\varphi$ implies that $\int_{X} \dot{\varphi} \omega_{X}^{n+m}=0$. We now compute the Laplacian of $\ddot{\varphi}$, by taking a derivative of (4.23) to get
$$\Delta \ddot{\varphi}=\left(\log c_{t}\right)^{\prime \prime}+\operatorname{tr}_{\omega} \chi-\operatorname{tr}_{\omega} \tilde{\omega}+|\sqrt{-1} \partial \bar{\partial} \dot{\varphi}+\chi-\tilde{\omega}|_{g}^{2},$$
and so $\Delta(\dot{\varphi}+\ddot{\varphi}) \geqslant-C$ and $\int_{X} \ddot{\varphi} \omega_{X}^{n+m}=0$.
The Ricci-flat metrics $\omega$ have a uniform upper bound on their diameter, thanks to [53] (and independently [64]), and have volume bounded below by $C^{-1} e^{-n t}$, by (4.5). Therefore the Green's function $G(x, y)$ of the Laplacian of $\Delta$ (normalized by $\int_{y \in X} G(x, y) \omega^{n+m}(y)=0$ ), satisfies
$$G(x, y) \geqslant-C e^{n t},$$
for a uniform constant $C$ (see e.g. [2, Theorem 3.2] or [35, Chapter 3, Appendix A]). Also, again from (4.5),
$$\int_{X}(\varphi+\dot{\varphi}) \omega^{n+m}=c_{t} e^{-n t} \int_{X}(\varphi+\dot{\varphi}) \omega_{X}^{n+m}=0,$$
and so the Green's formula for the metric $\omega$ and the bound $|\Delta(\varphi+\dot{\varphi})| \leqslant C$ imply that
$$\begin{aligned}
\sup _{X}(\varphi+\dot{\varphi}) & =-\int_{y \in X} \Delta(\varphi+\dot{\varphi})(y) G(x, y) \omega^{n+m}(y) \\
& =\int_{y \in X}(-\Delta(\varphi+\dot{\varphi})(y))\left(G(x, y)+C e^{n t}\right) \omega^{n+m}(y) \\
& \leqslant C e^{n t} \int_{X} \omega^{n+m} \leqslant C,
\end{aligned}$$
where $x$ is any point where $\varphi+\dot{\varphi}$ achieves its maximum. Similarly we get a lower bound for $\varphi+\dot{\varphi}$, and so we have shown
$$\sup _{X}|\varphi+\dot{\varphi}| \leqslant C,$$
which, together with $\sup _{X}|\varphi| \leqslant C$ (Lemma 4.1.(ii)), proves (4.21).
Next, since $\Delta(\dot{\varphi}+\ddot{\varphi}) \geqslant-C$ and $\int_{X}(\dot{\varphi}+\ddot{\varphi}) \omega_{X}^{n+m}=0$, exactly the same argument shows that
$$\sup _{X}(\dot{\varphi}+\ddot{\varphi}) \leqslant C,$$
which together with (4.21) proves (4.22). \(\square\)

Remark 4.5. One can feed the bound (4.25) into a Cheng-Yau type argument, exactly as in [37, Lemma 3.6], by applying the maximum principle to
$$Q=\frac{|\partial(\varphi+\dot{\varphi})|_{g}^{2}}{A-\varphi-\dot{\varphi}}+\operatorname{tr}_{\omega} \chi,$$
where $A$ is chosen so that $A-\varphi-\dot{\varphi} \geqslant A / 2>0$, and prove that
$$\sup _{X}|\partial(\varphi+\dot{\varphi})|_{g} \leqslant C .$$
However, we won't need this estimate.
The quantity $(\varphi+\dot{\varphi}-v)$ will play here the same role as in Section 3. Indeed, observe that from (4.24),
$$\Delta(\varphi+\dot{\varphi}-v)=m-\operatorname{tr}_{\omega} \omega_{B}+\left(\log c_{t}\right)^{\prime},$$
and $\left(\log c_{t}\right)^{\prime}=O\left(e^{-t}\right)$ (cf. (3.8)). The following lemma is analogous to part (iv) of Lemma 3.1.
Lemma 4.6. There is a positive function $H(t)$ with $H(t) \rightarrow 0$ as $t \rightarrow \infty$ such that
$$\sup _{X} \mathcal{F}|\varphi+\dot{\varphi}-v| \leqslant H(t) .$$
Proof. First we prove that $\limsup _{t \geqslant 0} \sup _{X} \mathcal{F}(\varphi+\dot{\varphi}-v) \leqslant 0$. Thanks to (4.12) it is enough to show that
$$\limsup _{t \geqslant 0} \sup _{X} \mathcal{F} \dot{\varphi} \leqslant 0 .$$
If this is not the case, then there exist $\varepsilon>0, x_{k} \in X$ and $t_{k} \rightarrow \infty$ such that
$$\sup _{X} \mathcal{F} \dot{\varphi}\left(t_{k}\right)=\mathcal{F}\left(x_{k}\right) \dot{\varphi}\left(t_{k}, x_{k}\right) \geqslant \varepsilon,$$
so in particular $x_{k} \notin S$. From Lemma 4.4 we see that
$$\frac{\partial}{\partial t}(\mathcal{F} \dot{\varphi})=\mathcal{F} \ddot{\varphi} \leqslant C,$$
and so
$$\mathcal{F}\left(x_{k}\right) \dot{\varphi}\left(t, x_{k}\right) \geqslant \frac{\varepsilon}{2}, \quad \text { for } t \in\left[t_{k}-\frac{\varepsilon}{2 C}, t_{k}\right] .$$
Integrating over $t$,
$$\mathcal{F}\left(x_{k}\right)(\varphi-v)\left(t_{k}, x_{k}\right) \geqslant \mathcal{F}\left(x_{k}\right)(\varphi-v)\left(t_{k}-\varepsilon / 2 C, x_{k}\right)+\frac{\varepsilon^{2}}{4 C},$$
but from (4.12) we have
$$h\left(t_{k}\right) \geqslant-h\left(t_{k}-\varepsilon / 2 C\right)+\frac{\varepsilon^{2}}{4 C},$$
for a positive function $h(t)$ with $h(t) \rightarrow 0$ as $t \rightarrow \infty$. Letting $k \rightarrow \infty$ we get a contradiction.

The inequality $\liminf _{t \geqslant 0} \inf _{X} \mathcal{F}(\varphi+\dot{\varphi}-v) \geqslant 0$ follows from a similar argument. Although we do not have a lower bound for $\ddot{\varphi}$, we can instead replace the time interval $\left[t_{k}-\frac{\varepsilon}{2 C}, t_{k}\right]$ by $\left[t_{k}, t_{k}+\frac{\varepsilon}{2 C}\right]$. \(\square\)

We can finally prove the following analogue of Lemma 3.4:
Lemma 4.7. Given a compact set $K \subset X \backslash S$, there is a positive decreasing function $F(t)$ which goes to zero as $t \rightarrow \infty$ such that
$$\sup _{K}\left(\operatorname{tr}_{\omega} \omega_{B}-m\right) \leqslant F(t) .$$
Proof. For the purpose of this proof, define a function $\tilde{\mathcal{F}}=e^{-e^{\tilde{A} \sigma^{-\lambda}}}$, with $\tilde{A}$ slightly larger than the constant $A$ of $\mathcal{F}$ used in (4.27). We will apply the maximum principle to
$$Q=\tilde{\mathcal{F}}\left(\operatorname{tr}_{\omega} \omega_{B}-m\right)-\frac{\tilde{\mathcal{F}}}{\sqrt{H(t)}}(\varphi+\dot{\varphi}-v),$$
where $H(t)$ is the function from (4.27).
We may assume, by increasing $\tilde{A}$ if necessary, that
$$\frac{|\nabla \tilde{\mathcal{F}}|^{2}}{\tilde{\mathcal{F}}} \leqslant C \mathcal{F}, \quad|\Delta \tilde{\mathcal{F}}| \leqslant C \mathcal{F},$$
where we used (4.3) and the Schwarz Lemma estimate $\operatorname{tr}_{\omega} \chi \leqslant C$. It follows from Lemma 4.6 that
$$|(\varphi+\dot{\varphi}-v) \Delta \tilde{\mathcal{F}}| \leqslant C H(t)$$
and
$$|\tilde{\mathcal{F}}(\varphi+\dot{\varphi}-v)| \frac{|\nabla \tilde{\mathcal{F}}|^{2}}{\tilde{\mathcal{F}}^{2}} \leqslant C H(t) .$$

Then we compute, using (4.26) and (4.30),
$$\begin{aligned}
& \Delta(\tilde{\mathcal{F}}(\varphi+\dot{\varphi}-v)) \\
\leqslant & -\tilde{\mathcal{F}}\left(\operatorname{tr}_{\omega} \omega_{B}-m-\left(\log c_{t}\right)^{\prime}\right)+2 \operatorname{Re}\langle\nabla \tilde{\mathcal{F}}, \nabla(\varphi+\dot{\varphi}-v)\rangle+C H(t) .
\end{aligned}$$
From Lemma 4.2, we have, for some $\lambda^{\prime}>0$,
$$\begin{aligned}
\Delta\left(\tilde{\mathcal{F}}\left(\operatorname{tr}_{\omega} \omega_{B}-m\right)\right) & \geqslant-C \tilde{\mathcal{F}} \sigma^{-\lambda^{\prime}}+\left(\operatorname{tr}_{\omega} \omega_{B}-m\right) \Delta \tilde{\mathcal{F}} \\
& +2 \operatorname{Re}\left\langle\nabla \tilde{\mathcal{F}}, \nabla\left(\operatorname{tr}_{\omega} \omega_{B}-m\right)\right\rangle \\
& \geqslant 2 \operatorname{Re}\left\langle\nabla \tilde{\mathcal{F}}, \nabla\left(\operatorname{tr}_{\omega} \omega_{B}-m\right)\right\rangle-C .
\end{aligned}$$
Hence
$$\begin{aligned}
\Delta Q & \geqslant \frac{\tilde{\mathcal{F}}}{\sqrt{H(t)}}\left(\operatorname{tr}_{\omega} \omega_{B}-m-\left(\log c_{t}\right)^{\prime}\right)-C+2 \operatorname{Re}\langle\nabla \tilde{\mathcal{F}}, \nabla(Q / \tilde{\mathcal{F}})\rangle \\
& =\frac{\tilde{\mathcal{F}}}{\sqrt{H(t)}}\left(\operatorname{tr}_{\omega} \omega_{B}-m-\left(\log c_{t}\right)^{\prime}\right)-C+\frac{2}{\tilde{\mathcal{F}}} \operatorname{Re}\langle\nabla \tilde{\mathcal{F}}, \nabla Q\rangle-\frac{2 Q}{\tilde{\mathcal{F}}^{2}}|\nabla \tilde{\mathcal{F}}|^{2} \\
& \geqslant \frac{\tilde{\mathcal{F}}}{\sqrt{H(t)}}\left(\operatorname{tr}_{\omega} \omega_{B}-m-\left(\log c_{t}\right)^{\prime}\right)-C+\frac{2}{\tilde{\mathcal{F}}} \operatorname{Re}\langle\nabla \tilde{\mathcal{F}}, \nabla Q\rangle,
\end{aligned}$$
where in the last line we used (4.31). At the maximum of $Q$ we have $\nabla Q=0$. We may assume without loss of generality that $\left(\log c_{t}\right)^{\prime} / \sqrt{H(t)} \rightarrow 0$ as
$t \rightarrow \infty$. Making use of Lemma 4.6, we obtain $Q \leqslant C \sqrt{H(t)}$. The result follows. \(\square\)

Another ingredient that we will need is the following local Calabi estimate, whose proof can be obtained by a straightforward modification of the proof of Proposition 2.7.
Proposition 4.8. Let $B_{1}(0)$ be the unit polydisc in $\mathbb{C}^{n+m}$ and let $\omega_{E}^{(n+m)}=$ $\sum_{k=1}^{m+n} \sqrt{-1} d z^{k} \wedge d \bar{z}^{k}$ be the Euclidean metric. Write $\mathbb{C}^{n+m}=\mathbb{C}^{m} \oplus \mathbb{C}^{n}$ and define $\omega_{E, t}=\omega_{E}^{(m)}+e^{-t} \omega_{E}^{(n)}$. Assume that $\omega=\omega(t)$ is a Ricci-flat Kähler metric which satisfies for $t \geqslant 0$,
$$A^{-1} \omega_{E, t} \leqslant \omega \leqslant A \omega_{E, t},$$
for some positive constant $A$. Then there is a constant $C$ that depends only on $n, m, A$ such that for all $t \geqslant 0$ on $B_{1 / 2}(0)$ we have
$$S=\left|\nabla^{E} g\right|_{g}^{2} \leqslant C e^{t},$$
where $g$ is the metric associated to $\omega$ and $\nabla^{E}$ is the covariant derivative of $\omega_{E}^{(n+m)}$.

We can now complete the proof of Theorem 1.3.
Proof of Theorem 1.3. The proof is similar to the proof of Theorem 1.2, so we provide here just a sketch. Fix a compact set $K^{\prime} \subset B \backslash S$ and write $K=\pi^{-1}\left(K^{\prime}\right)$. From Lemma 4.1,(i) and Proposition 4.8, as in the case of the flow, there is a constant $C$ such that
$$\left\|\left.e^{t} \omega\right|_{X_{y}}\right\|_{C^{1}\left(X_{y},\left.\omega_{X}\right|_{X_{y}}\right)} \leqslant C,\left.\quad e^{t} \omega\right|_{X_{y}} \geqslant\left. C^{-1} \omega_{X}\right|_{X_{y}},$$
for all $t \geqslant 0$ and for all $y \in K^{\prime}$.
On $X \backslash S$, write for any $y \in K^{\prime}$,
$$\begin{aligned}
\left(\left.e^{t} \omega\right|_{X_{y}}\right)^{n} & =e^{n t} \frac{\omega^{n} \wedge \omega_{B}^{m}}{\omega_{\mathrm{SRF}}^{n} \wedge \omega_{B}^{m}}\left(\omega_{\mathrm{SRF}, y}\right)^{n} \\
& =f\left(\omega_{\mathrm{SRF}, y}\right)^{n}, \quad \text { for } f=c_{t} \frac{\int_{X} \omega_{X}^{n+m}}{\int_{X} \omega_{X}^{n} \wedge \chi^{m}} \frac{\omega^{n} \wedge \omega_{B}^{m}}{\omega^{n+m}},
\end{aligned}$$
where we used (4.2) and (4.5). Note that when restricted to the fiber, $f$ is given by
$$\left.f\right|_{X_{y}}=\frac{\left(\left.e^{t} \omega\right|_{X_{y}}\right)^{n}}{\left(\omega_{\mathrm{SRF}, y}\right)^{n}} .$$
We have that
$$\int_{X_{y}} f\left(\omega_{\mathrm{SRF}, y}\right)^{n}=\int_{X_{y}}\left(\left.e^{t} \omega\right|_{X_{y}}\right)^{n}=\int_{X_{y}}\left(\left.\omega_{X}\right|_{X_{y}}\right)^{n}=\int_{X_{y}}\left(\omega_{\mathrm{SRF}, y}\right)^{n},$$
so that $f-1$ satisfies condition (b) of Lemma 2.4. Thanks to (4.7),
$$c_{t} \frac{\int_{X} \omega_{X}^{n+m}}{\int_{X} \omega_{X}^{n} \wedge \chi^{m}} \rightarrow\binom{n+m}{n},$$
as $t \rightarrow \infty$. Moreover, as in (2.19), using Lemma 4.7,
$$\binom{n+m}{n} \frac{\omega^{n} \wedge \omega_{B}^{m}}{\omega^{n+m}} \leqslant\left(\operatorname{tr}_{\omega} \omega_{B} / m\right)^{m} \leqslant 1+H(t),$$
for $H(t) \rightarrow 0$ as $t \rightarrow \infty$. Hence $f-1 \leqslant h(t)$, with $h(t) \rightarrow 0$ as $t \rightarrow \infty$. Finally, $f$ satisfies $\left|\nabla\left(\left.f\right|_{X_{y}}\right)\right|_{\left.\omega_{X}\right|_{X_{y}}} \leqslant A$ for all $y \in K^{\prime}$. Applying Lemma 2.4 to $f-1$ on $K$ (see Remark 2.5), $f$ converges to 1 uniformly on $K$. Namely,
$$\left\|\left(\left.e^{t} \omega\right|_{X_{y}}\right)^{n}-\omega_{\mathrm{SRF}, y}^{n}\right\|_{C^{0}\left(X_{y},\left.\omega_{X}\right|_{X_{y}}\right)} \rightarrow 0, \quad \text { as } t \rightarrow \infty,$$
uniformly as $y$ varies in $K^{\prime}$. It follows that for any given $y \in K^{\prime}$ we have
$$\left.e^{t} \omega\right|_{X_{y}} \rightarrow \omega_{\mathrm{SRF}, y}, \quad \text { as } t \rightarrow \infty,$$
in $C^{\alpha}$ on $X_{y}$, for any $\alpha \in(0,1)$.
Next we show that
$$\left\|\left.e^{t} \omega\right|_{X_{y}}-\omega_{\mathrm{SRF}, y}\right\|_{C^{0}\left(X_{y},\left.\omega_{X}\right|_{X_{y}}\right)} \rightarrow 0, \quad \text { as } t \rightarrow \infty,$$
uniformly for $y \in K^{\prime}$. To see this, define
$$\left.f\right|_{X_{y}}=\frac{\left(\left.e^{t} \omega\right|_{X_{y}}\right) \wedge \omega_{\mathrm{SRF}, y}^{n-1}}{\omega_{\mathrm{SRF}, y}^{n}} .$$
While this is defined on $X_{y}$, it is clearly smooth in $y$ and so defines a smooth function $f$ on $X \backslash S$, which equals
$$f=\frac{e^{t} \omega \wedge \omega_{\mathrm{SRF}}^{n-1} \wedge \omega_{B}^{m}}{\omega_{\mathrm{SRF}}^{n} \wedge \omega_{B}^{m}}=c_{t} \frac{\int_{X} \omega_{X}^{n+m}}{\int_{X} \omega_{X}^{n} \wedge \chi^{m}} \frac{\omega \wedge\left(e^{-t} \omega_{\mathrm{SRF}}\right)^{n-1} \wedge \omega_{B}^{m}}{\omega^{n+m}} .$$
By the same argument as in the proof of (1.6) in Section 2, we see that $f$ converges 1 as $t \rightarrow 0$ and hence
$$\left\|\left(\left.e^{t} \omega\right|_{X_{y}}\right) \wedge \omega_{\mathrm{SRF}, y}^{n-1}-\omega_{\mathrm{SRF}, y}^{n}\right\|_{C^{0}\left(X_{y},\left.\omega_{X}\right|_{X_{y}}\right)} \rightarrow 0, \quad \text { as } t \rightarrow \infty,$$
uniformly as $y$ varies in $K^{\prime}$. From (4.38) and (4.40), we apply Lemma 2.6 to obtain (4.39) as required.

It remains to prove part (i) of Theorem 1.3. Define $\hat{\omega}=\hat{\omega}(t)$ by
$$\hat{\omega}=e^{-t} \omega_{\mathrm{SRF}}+\left(1-e^{-t}\right) \omega_{B} .$$
By the same argument as in the proof of Theorem 1.2.(i), we have on $K$,
$$\operatorname{tr}_{\omega} \hat{\omega}-(n+m) \leqslant h(t) \rightarrow 0,$$
for a positive decreasing function $h(t)$ (depending on $K$ ). On the other hand, again on $K$,
$$\begin{aligned}
\frac{\hat{\omega}^{n+m}}{\omega^{n+m}} & =\binom{n+m}{n} \frac{e^{-n t} \omega_{\mathrm{SRF}}^{n} \wedge \omega_{B}^{m}}{\omega^{n+m}}+O\left(e^{-t}\right) \\
& =\frac{\binom{n+m}{n} \int_{X} \omega_{X}^{n} \wedge \chi^{m}}{c_{t} \int_{X} \omega_{X}^{n+m}}+O\left(e^{-t}\right) \rightarrow 1, \quad \text { as } t \rightarrow \infty .
\end{aligned}$$
Applying Lemma 2.6, we have $\|\omega-\hat{\omega}\|_{C^{0}(K, \omega)} \rightarrow 0$ and part (i) of Theorem 1.3 follows. \(\square\)
