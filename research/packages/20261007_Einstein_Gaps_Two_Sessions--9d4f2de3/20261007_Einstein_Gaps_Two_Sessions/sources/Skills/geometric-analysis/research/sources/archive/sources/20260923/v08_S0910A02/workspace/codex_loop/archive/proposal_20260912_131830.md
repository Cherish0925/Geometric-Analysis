# Research Project Proposal

## Research Objective

Help advance the Yau Problem 26 positive-branch experiment on the chi=8 positive-mirror rows by prototyping a **decoupled naive-start Einstein-DeTurck / variational flow pipeline**. The refined Biquard correction `h` is still being exported separately; the existence-oriented experiment does not require small initial Ricci defect. The immediate scientific goal is to determine whether the numerical machinery can converge on the known control row and produce interpretable evidence on the balanced rows.

## Current Progress

The main Qiushi session has constructed a candidate frontier around the positive mirror orbifold `(S^2 x S^2)/Z_2` with four A1 singularities and mixed Eguchi-Hanson fillings. Step 64 classified the rows:

- r=0: `#CP2#5CP2bar` (degree-4 del Pezzo anchor; known positive Kähler-Einstein metric)
- r=1: `#2CP2#4CP2bar`
- r=2: both `#3(S2xS2)` (spin seam pattern) and `#3CP2#3CP2bar` (non-spin seam pattern)
- r=3: `#4CP2#2CP2bar`
- r=4: reverse of r=0

All mixed rows satisfy strict Hitchin-Thorpe and remain viable candidates; no branch of Yau26 has been proved or refuted.

Step 65 attempted to export the refined Biquard correction on EH and derived a full-4D U(2)-invariant linearized Ricci system, but did not solve the BVP. Step 66 produced a solver-agnostic first-order operator-norm audit and showed:

- raw EH insert (`h=0`) has O(1) core defect and is not a near-pinched certificate;
- the Kähler-potential scalar identity is locally correct but cannot solve the global smooth Biquard problem because of the EH bolt cohomology/obstruction term;
- the exact audit interface is independent of BVP convergence and can check any supplied radial profile;
- for existence search, naive smooth starts are legitimate, and the known del Pezzo r=0 row should be the control.

## Task For Codex

Build a **bounded prototype** for the naive-start control-flow experiment. This is not expected to solve the full PDE on a four-manifold in one run; it should create an inspectable minimal pipeline with controls and failure taxonomy.

Preferred route:

1. Implement a low-dimensional symmetry-reduced toy Einstein-DeTurck or Ricci-gradient/variational flow that captures the same experimental discipline:
   - a known positive KE/control case analogous to the r=0 del Pezzo row;
   - a balanced/mixed-row-like case with four EH seam parameters or at least four local defect wells;
   - symmetry preservation (`Z2 x Z2`-like) built into the variables.
2. Include the pre-registered readout:
   - solver converges on control? if no, mixed-row behavior uninterpretable;
   - on mixed case, distinguish seam re-collapse from interior concentration/divergence;
   - record defect norms over time and a mechanism label.
3. Integrate the Step-66 operator-norm audit concept: the code should compute a direct sup norm of the Ricci-endomorphism/Einstein defect or its model analogue at every saved time, not merely report solver residual.
4. If the full flow prototype is too ambitious, produce instead a precise design + runnable smaller module that audits naive/refined starts on radial EH profiles and lays out the exact finite-element/FEniCSx objects needed for the true four-dimensional experiment.

Do **not** claim a proof or counterexample. Do **not** upgrade nonconvergence to nonexistence. Do **not** spend the task trying to solve the refined Biquard `h` BVP; the main session is treating that separately.
