# 2026-10-11：光滑最优度量取得性的直接续研

本包接续既有轨形／有理球退化工作，集中于第三题：构造并证明一个闭四维流形上的光滑全局 P 极小元不满足 Bach-flat。P=∫|Ric°|²。这个最终结论本轮尚未获得。

先读 `Rational_Ball_Variation_20261011.pdf` 或同名独立 LaTeX，共4页。正文记录本轮实际完成的两项计算和未消失的外部配对。

1. 对普通 B₂=EH/Z₂ 的指定双轴二次渐近数据，显式解出光滑线性响应，并证明所有保持该渐近数据、满足所列衰减及可积性的修正都有精确最小二次缺陷 π²μ²/2。这是指定内核变分问题的答案；允许非双轴修正，但不覆盖任意背景曲率射流。
2. 对一个能下降到 B₂ 的调和角向分量，算出内核重整化差 −16π²/3；再完整计算截断过渡区，得到 −3L∫[ρ³(χ″)²+3ρ(χ′)²]。后者依赖截断轮廓，长对数过渡使其趋零。因此前一个负数不能被单独当成固定闭流形的节省。
3. 外部配对涉及 JJ:∇²E，而主临界方程约束 ΔE。已写出满足迹、散度和主临界方程、却具有非零配对的四阶射流。这是局部形式计算，不是全局临界度量或几何反例。

这批计算使用了经典 Eguchi–Hanson Jacobi 场和曲率变分恒等式；不将经典内核、质量公式或文献定理记作本轮原创。代数程序验证有理函数与系数，不能验证尚未建立的全局匹配。
