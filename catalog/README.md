# Archive catalogue

The [manuscripts](../manuscripts/README.md) and [mathematical source guide](../docs/COVERAGE.md) organize the research by subject. This catalogue provides access to the underlying texts, computations, and earlier versions.

## Documents

- [Original manuscripts and sources](ORIGINAL_SOURCES.md)
- [Source packages and their contents](PACKAGES.md)

## File records

- [Source records](sources.json): original titles and archive locations.
- [Package records](packages.json): archives and extracted directories.
- [Archive contents](archive_members.json): files within the source packages.
- [Repository files](files.json): paths, sizes, and file types.

The catalogue is generated by `python3 tools/build_catalog.py`.
