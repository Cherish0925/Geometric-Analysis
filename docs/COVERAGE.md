## 完整性与继续使用

每份原件及解包成员均记录字节数和 SHA256；完整仓库清单还记录 Git blob SHA。可在仓库根目录运行：

```sh
python3 tools/check_archive.py --full
```

新增材料后，保留原件，更新相应来源记录与专题导航，再运行 `python3 tools/build_catalog.py` 重建文件目录。

数学状态采用原稿的实际陈述及后续更正。文件完整性核对不增加、撤销或自动认证任何数学定理。
