# Yau Problem 26 第一科学主线

## 四维 Seiberg–Witten 曲率障碍、Einstein 方程与定量稳定性的统一研究计划

### 最高研究目标

当前第一科学主线已经形成真实的核心成果：

* 实际／逐极化 monopole 输入；
* 无非塌缩、无统一 Sobolev 假设的积分 Einstein 刚性；
* LeBrun 经典 Einstein obstruction 的定量稳定性加强；
* \(b_+=1\)、正权重、Ricci-flat 等接口的闭合；
* 参数化曲率泛函；
* 实际辅助二形式供给；
* 双手性曲率预算；
* 超出旧 \(1/3\) 临界带的新全局拓扑间隙；
* 允许谱上的定量结构控制。

这些成果作为**稳定基线**继承，不重复“重新发现”。

接下来的最高目标不是继续增加孤立估计，而是：

> **建立一套真正统一的四维 quantitative Einstein geometry：把 Seiberg–Witten / monopole 拓扑、曲率泛函、Weyl 谱、Einstein 方程、近等号结构、退化／塌缩和精确存在性组织为一个能够不断产生新定理的理论。**

最终希望达到的理想形式是：

\[
\boxed{
\text{拓扑／规范理论输入}
\Longrightarrow
\text{曲率近饱和结构}
\Longrightarrow
\begin{cases}
\text{定量障碍},\\
\text{刚性／分类},\\
\text{精确 Einstein 实现}.
\end{cases}}
\]

并使该理论成为研究 Yau26 四维情形的核心组成部分，而不是只停留在 LeBrun 2001 某个推论的加强。

## 一、把现有成果提升成一个真正的 Master Theory

当前不能再把：

\[
\mathcal E(g)+\left(\frac13-h\right)_+\ge c,
\]

参数化泛函、

\[
\mathfrak D_\beta,
\]

以及双手性间隙分别看作互不相关的结果。

应重新寻找它们背后的**最小统一机制**。

目标是抽象出：

\[
\boxed{\text{Quantitative Monopole--Curvature Compatibility Theorem}}
\]

它的输入尽量只包含：

* 一个真实可解的 gauge-theoretic class system；
* 周期平面／投影预算；
* 类平方或负平方成本；
* 必要的曲率泛函数据。

输出则统一控制：

* Einstein defect；
* scalar–Weyl functional deficit；
* Weyl 模型偏离；
* auxiliary form 的导数／模长；
* equality-mode distance；
* 必要时的 chiral curvature budgets。

不要预设最终 master theorem 必须只有一个公式。

更合理的形式可能是一组彼此兼容的 coercive inequalities，共享同一个规范理论发动机。

## 二、进一步抽象 gauge-theory 输入，而不是永远停留在一般型复曲面 blow-up

当前已经完整覆盖 LeBrun 经典 blow-up / connected-sum 的正预算范围，这是重要成果，但不是理论终点。

应系统研究：

* ordinary SW basic classes；
* generic monopole classes；
* special monopole classes；
* Bauer–Furuta stable cohomotopy classes；
* monopole convex hull；
* 多个 actual classes 的同时近饱和；
* 两个取向的实际类系统；
* 与 symplectic canonical classes 无关的 gauge input。

核心问题不是：

> “还能不能找到更多 basic classes？”

而是：

> **现有积分校准证明真正需要的最弱 gauge-theoretic 输入是什么？**

理想目标是将 class-supply 与 analytic theorem 完全分离：

\[
\boxed{\text{任何能提供规定投影／平方／加权可解性的理论}
\Longrightarrow\text{同一个 Einstein-stability conclusion}.}
\]

若能够做到，Bauer–Furuta、Kotschick、Ishida–LeBrun、LeBrun convex geometry 等将成为统一理论的不同“输入模块”，而不是平行文献。

## 三、双手性拓扑间隙应继续发展成真正的“可行区域几何”

最新结果表明，仅使用经典临界比值 \(h\) 并不足够；加入另一半 Weyl 非负性后，可以用

\[
(h,U)
\]

描述更大的不相容区域。

这暗示应该研究：

\[
\boxed{\mathcal R_{\rm admissible}\subset\{(h,U,\ldots)\}}
\]

即：

> 哪些拓扑／曲率预算组合能够与 arbitrarily small Einstein defect 相容？

不要只继续优化

\[
F(h)
\]

某个常数。

应尝试寻找更多**真正独立的全局预算**：

* 两个手性的 Weyl 能量；
* signature/Euler 比值；
* simplicial volume / entropy；
* monopole convex-hull geometry；
* period-plane volume；
* harmonic-form Gram data；
* representation volume；
* Bauer–Furuta 型稳定信息；
* 其他 Chern–Weil 组合。

每增加一个预算，都必须回答：

> 它是否排除了此前真实允许的候选区域？

如果没有改变 admissible region，就不要把它当作主成果。

理想终点是一个几何上可解释的“Einstein-feasibility region”，而不是几十条彼此孤立的不等式。

## 四、系统研究 Sharpness：不仅证明 gap，还要理解边界为何锐利

顶级理论不只应有：

\[
\text{gap}>0.
\]

还应理解：

* 哪些序列逼近 gap；
* gap 是否最优；
* 哪些 equality / near-equality 模型真实存在；
* 常数在什么族中必须退化；
* 哪些假设不可删除。

应系统寻找：

\[
\boxed{\text{extremizers / near-extremizers / counterexamples}.}
\]

包括但不限于：

* Kähler–Einstein；
* cscK 非 Einstein；
* hyperbolic products；
* complex hyperbolic；
* locally symmetric but reducible geometries；
* orbifold/ALE degeneration；
* sheared almost-Einstein metrics；
* volume-dilution examples；
* collapsing Einstein sequences。

如果一个新定理没有经过这些真实模型压力测试，不应称为最优或通用。

## 五、第21轮允许谱应发展成“Equality-Mode Theory”，而不是只继续禁谱

当前结果已经表明，某些近Einstein/Weyl模型只能接近：

\[
t=0\quad\text{或}\quad t=-\sigma/2.
\]

下一步不能只继续证明：

\[
t\notin\{\cdots\}\Rightarrow\text{gap}.
\]

更重要的问题是：

> **允许根到底意味着什么真实几何？**

对 \(t=0\)：

* 是否出现 ASD / definite-connection rigidity？
* 哪些局部模型真实存在？
* global topology 能否容许？
* 是否存在 deformation / moduli obstruction？

对 KE 根：

* 什么时候近Kähler结构能提升为真实Kähler结构？
* 什么时候可以得到 integrability？
* 什么时候能够进一步升级为 Kähler–Einstein？
* 是否存在非Kähler精确 Einstein 度量具有任意小谱分裂？
* zero set / eigenline monodromy / finite covers 如何影响结论？

需要把 Derdziński、LeBrun、Sekigawa、Fine–Krasnov、Catino–Dameno、LeBrun–Ozuch 等理论视作**不同可能出口**，而不是简单拼在一个证明中。

目标可以是：

\[
\boxed{\text{small spectral splitting}
+\text{exact Einstein}
+\text{明确拓扑／非退化条件}
\Longrightarrow\text{exact geometric rigidity}.}
\]

或者反过来构造严格反例，说明这类 rigidity 不成立。

两种结果都很有价值。

## 六、从“平均结构”跨向“全局结构”是目前最重要的开放层

\[
\fint|W^+-A_\omega|^2\ll1,

\[
\text{局部Kähler型}\not\Rightarrow\text{全局Kähler},
\]

\[
\text{允许谱}\not\Rightarrow\text{存在精确Einstein}.

这一层是真正值得发明新工具的地方。

可以探索：

* quantitative integrability；
* gauge-fixed deformation theory；
* spectral flow / determinant line bundle；
* harmonic map / harmonic morphism machinery。

不要预设一定来自 Seiberg–Witten。

**只要能把当前“平均结构”变成“全局判别”，就是第一主线的重要突破。**

## 七、将 collapse / noncollapse 真正并入理论，而不是只作为困难说明

Yau26 没有非塌缩假设，因此第一主线若想走向原题，最终必须正面面对 collapse。

但不要先追求“分类所有 bounded-Ricci collapse”。

应该利用当前问题的额外结构：

\[
\Ric\approx\pm g
\]

以及：

* monopole near-saturation；
* chiral curvature budgets；
* characteristic classes；
* actual forms；
* spectral restrictions。

然后与：

* Cheeger–Naber；
* Naber–Zhang；
* Jiang–Naber；
* Rong / bounded-Ricci covering geometry；
* Lott groupoid / orbit-volume identities；
* Uhlenbeck；
* Ozuch degeneration；

做**有假设的精确连接**。

可能的高价值目标：

\[
\boxed{\text{near-Einstein + gauge saturation}
\Longrightarrow\text{collapse rank / local cover / curvature structure constraints}.}
\]

如果能证明 collapse 必须属于某些 Einstein-compatible 类型，那么这会直接推进 Yau26。

如果能证明某些 topology 强制产生不可避免的点态 anisotropy，也同样重要。

## 八、重新认真考虑 Ricci flow，但不要把 Yau26 等同于 Ricci flow convergence

可以研究：

* static defect 在 normalized Ricci flow 下的演化；
* monopole calibration density 是否存在单调／准单调结构；
* 第21轮谱量是否有动态传播；
* 某些允许分支是否通过短时流进入更规整的 moduli neighborhood；

但始终保留：

\[
\text{某个输入的 Ricci flow 不收敛}
\not\Rightarrow\text{底层流形没有 Einstein metric}.
\]

Ricci flow 是一个可能的 regularization / deformation module，不是 Yau26 的定义。

* Kähler–Einstein existence；

理想二分：

\[
\boxed{\text{near-Einstein input}

\text{or exact Einstein realization}.
\end{cases}}
\]

如果第一主线最终形成这种 obstruction/existence dichotomy，它与Yau26的关系会比目前强很多。

## 十一、建立理论的“失败边界”也是顶级贡献

当前已经知道：

* unconditional integral gap 不成立；
* cscK equality 不意味着 Einstein；
* Yamabe normalization 可能破坏点态Ricci控制；
* 近平行形式不保证全局Kähler；
* 一些经典障碍对特定拓扑完全失效。

不要把这些只记作“失败”。

应考虑形成：

\[
\boxed{\text{No-go / sharpness / failure theory}.}
\]

一个成熟理论应同时回答：

* 为什么现有假设足够？
* 去掉什么以后结论变假？
* 反例是什么？
* 哪一个量真正缺失？

如果能精确刻画 minimal hypotheses，这本身就是领域贡献。

## 十二、研究组织：禁止再次坍缩成“发现缺口→下一轮补缺口”

以后每个主任务必须落入以下四种之一：

* **新主定理**：扩大适用范围、减弱假设或增强结论；
* **sharpness theorem / counterexample**：确定理论边界；
* **existence theorem**：把允许结构实现成精确Einstein；
* **bridge theorem**：第一次严格连接两个此前独立的理论模块。

除此之外的技术引理，只能作为这些主任务的从属工作。

不要让：

* 一个新的系数；
* 一个新的截断；
* 一个新的模型；
* 一个新的数值复算；
* 一个新的局部排除；

自动成为下一轮最高目标。

## 十三、当前最值得同时维持的三个“大问题”

不要求每轮同时全部推进，但整个第一主线应该始终保留：

### A. Quantitative obstruction theory

尽可能扩大：

\[
\text{topology}\Rightarrow\text{uniform near-Einstein gap}.
\]

### B. Equality / allowed-mode theory

理解：

\[
\text{small defect}\Rightarrow\text{哪些真正几何结构？}
\]

\[
\text{允许结构}\Rightarrow\text{是否存在同一光滑流形上的Einstein metric？}
\]

只有 A 而没有 B/C，会停留在一个很强的障碍理论。

A、B、C 真正闭合，才可能形成对 Yau26 四维情形决定性的理论。

# 最终成功标准

第一主线“做到极致”不是：

> 论文越来越长、结果越来越多。

而是最终出现类似：

\[
\boxed{\text{一个新的理论框架}}
\]

它能够：

* 恢复并严格加强经典LeBrun–SW结果；
* 接纳更广gauge input；
* 给出新的真实拓扑障碍；
* 有接近最优的sharpness理论；
* 描述near-equality几何；
* 对允许分支给出精确实现或严格反例；
* 与collapse / moduli / flow产生真正定理级连接；
* 对Yau26四维情形形成实质性的存在／不存在判别。

**这才是“极致”。**

因此，接下来不要问：

> “还能不能再加强这个常数？”

而应该持续问：

> **“当前理论还看不见哪一种真实几何信息？如果把它看见，会不会改变Einstein存在性这个最终判断？”**

如果答案是会，那么那里就是下一次真正值得投入的数学突破点。
