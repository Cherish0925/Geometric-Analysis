# 数学发展与证明关系

Shuxing Yang, Junyao Wu, Rui Zhao, Hongsheng Chen, Yihao Yang  
Qiushi Engine Team, Zhejiang University · [作者与通讯信息](../AUTHORS.md)

本研究讨论 Einstein 方程的积分与点态逼近、曲率泛函的极值，以及近似解的精确修正。本文说明各项估计与构造之间的数学联系；完整假设和证明见相应专题。

## 1. 点态逼近、积分逼近与精确存在

点态逼近使用缺陷

```math
\delta_\sigma(g)=\|\operatorname{Ric}_g-\sigma g\|_{L^\infty(g)},\qquad \sigma=\pm1.
```

固定轨形的 ALE 解消与固定剪切曲面丛上的慢变形提供两类逼近：前者集中在收缩核心，后者沿越来越长的区域分散误差。它们表明，局部方程误差可以趋零而全局几何仍发生显著变化。

积分问题使用

```math
P(g)=\int|\operatorname{Ric}^{\circ}|^2,\qquad
\mathcal E(g)=\inf_{\lambda\ne0}\frac{\int|\operatorname{Ric}-\lambda g|^2}{\lambda^2V}.
```

四维中的整体缩放不改变这两个量。点态误差、体积和集中尺度共同决定积分缺陷，因而点态构造不能省略体积信息直接转为归一化极值结论。

固定剪切流形 $`E_D`$ 的逼近序列、非 Kähler 有限覆盖拓扑、整数剪切产生的多块周期，以及具有标记边界的非紧精确模型分别保留了不同的全局信息。精确实现定理分别利用直径和体积控制、完整填充条件或慢模态逆估计。证明见[点态逼近与精确实现](CONSTRUCTIONS_AND_REALIZATION.md)。

双曲连接区域的相对曲率公式说明了体积项的作用。对精确双曲外部的替换，曲率恒等式保留被移去的尖点体积；Weyl 能量与体积差可以互相抵偿。格商塌缩同时缩小所有积分，不能单独产生新的障碍。四节点轨形模型中的逐次数手性相消则解释了各节点之间的曲率耦合，完整的非线性解消仍需自作用和补空间响应。

## 2. 曲率积分下界与规范场的微分相容性

经典单极子估计给出标量与 Weyl 曲率的联合下界，Chern–Weil 公式将其转为拓扑约束。参数泛函

```math
D_\beta=(1+\beta^{-1})\int s^2+6(\beta+1)\int|W^+|^2-72\pi^2p
```

表示这些曲率下界，其中 $`p=(a_g^+)^2`$ 是所选单极子类的自对偶投影平方。

强制估计进一步使用场所选定的曲率模型、协变 Hessian 和弱 Bianchi 恒等式。证明先消去与实际场相容的背景作用，再估计偏差；若直接估计整个背景曲率，会保留一个不能在近饱和极限中吸收的常数。

两个参数值给出不同的几何结论。$`\beta=2`$ 对应可积 Kähler 校准，四项缺陷分解识别梯度、曲率模型和标量超额；$`\beta=8`$ 恰好与拓扑组合对齐：

```math
D_8=108\pi^2(T-2p/3)+\frac{27}{2}P,\qquad T=2\chi+3\tau.
```

因此同一分析分别导出线性强制和临界积分间隙。这解释了共同机制，也保留了两条结论所处参数区域的差别。

## 3. 共形归约与更自然的类平方条件

令 $`R=\int|\operatorname{Ric}|^2`$、$`\mathcal J=4P/R`$。精确恒等式

```math
\mathcal E=\mathcal J+\frac{\int s^2-(\int s)^2/V}{R}
```

分离了无迹 Ricci 与标量方差。负 Yamabe 替换后，$`P`$ 和 $`R`$ 的变化由同一个标量平方超额决定，$`\mathcal J(g)`$ 是 $`\mathcal J(\widehat g)`$ 与 $`1`$ 的加权平均。因此在低缺陷极值问题中可转到常标量代表，并得到相应的 $`\inf\mathcal E=\inf\mathcal J`$。

无迹 Ricci 间隙定理给出

```math
\mathcal J+(T/A-2/3)_+\ge\varepsilon.
```

保留类平方项后，上式进一步写成

```math
\mathcal J+(T/A-2/3)_+\ge\frac{c_*}{1+(-a^2)_+/(2\pi^2A)}.
```

因此，当 $`0\le a^2<T`$ 时，该无迹 Ricci 间隙估计的右端仍为 $`c_*`$。相对拓扑阈值的短缺 $`(T-a^2)_+/A`$ 仍适于与标量超额的联合估计比较。

这些估计减弱了解存在性假设：指定代表上的一个解给出该代表及其共形类的结论；全度量结论要求每个共形类均有满足投影下界的相应解。推导及普通 SW、special monopole、BF、Pin$`^-`$ 的应用见[间隙与端点](GAPS_AND_ENDPOINTS.md)。

## 4. 参数端点、第五张量幂线丛与拓扑范围

有限参数估计不能直接保证参数走向端点时常数保持正值。端点研究将实际扭率经过同丛预解算子转为有界截面，再构造行列式线丛第五张量幂上的截面

```math
\sigma=\Phi\wedge t(v)\in\Gamma(L^5).
```

在每个固定有限 Euler 密度范围内，场方程给出该截面的正 $`L^2`$ 下界及导数估计。对数正则化与 Chern 配对使一个几乎处处正模长的截面同非零陈数平方发生矛盾；另一条证明使用同一线丛上的弱 Cauchy–Riemann 方程和正势。

所得有限密度定理的常数为 $`c(B)>0`$，$`B`$ 是 $`\chi/A`$ 的固定上界。增长能量估计、双重带权测试及低幅度控制进一步限制逃逸方式，但没有证明 $`\inf_Bc(B)>0`$。

在许多实际手术范畴，统一端点已经可由现有结果得到。若

```math
Q=A-T\ge0,\qquad \chi\le CA+Q,
```

则 $`Q/A\ge1/3`$ 由无迹 Ricci 间隙定理控制；另一区间自动具有固定密度界。固定比例端点定理另由经典曲率积分估计与整共形类上的解存在性条件扩大适用范围。

这两种机制分别利用有限密度范围内的场方程与陈数矛盾，以及拓扑关系所给的参数区间分解。

## 5. 曲率极值与插入构造中的背景相互作用

在指定平衡族中，线性强制估计与恢复构造确定了归一化缺陷的线性阶。标准拼接上界的一阶系数为 $`4`$，但这些上下界没有决定该系数最优。

完整光滑插入构造给出严格小于 $`4`$ 的一阶上界。其解析机制在固定复双曲领口中表现为

```math
\frac{P(g_\epsilon)}{8\pi^2}=1-9\epsilon^2\log(1/\epsilon)+O_R(\epsilon^2).
```

负对数项来自背景与插入几何的相互作用，并压过内核和外过渡的二次误差。一般背景的 Burns 响应进一步记录插入方向与自对偶曲率算子的配对。覆盖空间中的恢复构造将局部能量减小转化为闭流形上的严格上界。

因此，标准核心各自的曲率能量不能充当全部竞争度量的可加下界。普通 AE 核心的相对曲率恒等式仍在其边界条件下成立；带背景曲率的领口、非平凡端群的 ALE 核心和不同拓扑标记各有额外项。

严格低于标准能量的插入构造还可以保留全局相容辛形式；将其共形化为几乎 Kähler 代表时，异常周期趋零会使标量平方能量发散。这解释了为何辛性本身不能恢复标准核心的能量下界。

变分分析利用 $`P`$ 的近驻点、近稳定选择，Weyl–Yamabe 可行域，完整曲率的精确归约以及解消时的混合曲率转移约束全部竞争者。在成对 $`A_1`$ 轨形等指定范畴，可将恢复上界与下界匹配并判断非取得性；一般吹起流形的最优值仍未由这些特殊范畴决定。详见[曲率变分](CURVATURE_VARIATION.md)。

## 6. 多个单极子类与 Hodge 分解的联合约束

双取向研究将两个单极子类的平方估计与交叉配对一起使用。若 $`a=x+y`$、$`b=x-y`$，则同一度量的 Hodge 分解必须同时实现

```math
a^2=2\chi+3\tau,\qquad b^2[M]=-2\chi+3\tau,\qquad a\cdot b=-3\tau.
```

因此，一侧接近临界极限时，另一侧的投影不能独立选择。结合固定密度端点定理，得到曲面丛的统一分离

```math
\mathcal J+\left(1-\frac{3|\tau|}{\chi}\right)_+\ge\varepsilon_{\mathrm{SB}}>0.
```

在 Kodaira 纤维化的负 Kähler–Einstein 度量上代入 $`\mathcal J=0`$，推出 $`c_1^2/c_2\le3-\varepsilon_{\mathrm{SB}}`$。

这个应用的反证序列始终处于一个固定有限密度范围，所以它不依赖一般无密度端点或一般曲率极值问题的解答。经典双取向论证已给严格不等式；有限密度端点定理进一步给出整个范畴上的统一分离常数。一侧凸包推广在使用场方程时选取具有解的单极子类；凸组合仅用于交叉形式的估计。

## 7. 慢模态、周期与精确修复

固定幅度慢变形保持周期，局部缺陷却随覆盖增长而趋零。因此，到精确解的距离还取决于慢模态及其周期。

在循环覆盖的双曲曲面乘积范畴，保留全部 Teichmüller 核后，可证明非线性修复定理：核补逆损失为 $`m^2`$，修复邻域为 $`cm^{-2}`$，相应慢模态表明该逆算子增长阶不可改进。核维数的增长通过统一投影估计处理，而非被当作可忽略的有限维常数。

另一条实现机制沿完整闭路积分实际纤维变形，以 Teichmüller 位移控制单值表示。在固定亏格和厚部条件下，足够小的全生成闭路变形产生有限单值性及精确乘积商。长领口 Dehn twist 和退化纤维分别说明累计量与厚部条件的作用。

另一个修复分支使用完整线性化的正强制及实际球体积增长。指数权的衰减超过体积增长时，可把局部小残差转换成统一逆估计；残差分布于越来越大总体积的覆盖上也允许修复。这给出了有明确增长与谱条件、但无直径上界的实现结论。

## 8. 负 Einstein 几何中的可积性与退化

显式非紧模型经零截面延拓，给出 $`\mathbb R^4`$ 上完备、非齐性的严格几乎 Kähler–Einstein 度量，满足 $`\operatorname{Ric}=-3g`$、$`W^-=0`$。它回答 Fino 所述允许非紧底空间的非不变存在性问题。闭流形上的负 Goldberg 猜想另要求紧致性。

闭流形上的分析涉及扭率零点的局部结构、典范联络正交、调和形式乘积及 Weyl 方程。Green 势方法将一个扭率零点处的势符号变为全局刚性；调和秩一矩阵将相容结构问题写成有限维二次约束；固定负 Kähler–Einstein 度量上的长度缺陷给出相容结构的局部孤立性。

局部 Darboux 表示进一步识别了线性 Einstein 方程除 Bianchi 之外的标量相容条件，以及不能作为规范删去的曲率自由度。整体上，典范联络减去标量校准给出的闭二形式在伪全纯曲线上非负；典范类与异常类的伪全纯流代表因而给出含拓扑项和面积项的扭率积分下界。局部可解性、形式延拓与整体曲线约束在此承担不同作用。

退化分析还利用两条含相反符号的全局缺陷恒等式：一条记录 Weyl 能量，另一条记录典范类平方。保留非负缺陷后，可在所述固定数据和收敛条件下排除正手性 Weyl 与扭率的集中。规范化 Einstein 作用在解析模空间的连通分支上常值，从而约束具有 Kähler–Einstein 轨形端点的分支。

上述刚性结果适用于所述曲率、模空间或退化条件。一般闭负 Goldberg 猜想仍未解决。详见[几乎 Kähler–Einstein 几何](GOLDBERG.md)。

## 9. Wahl 收缩：实际场、字符与形式方程

有理球收缩中的实际场转移保留类平方、正手性拓扑组合和相应 Dirac 指标，但反手性组合发生明确变化。局部字符能强迫旋量及一阶导数为零；在指定标记和实际类族中，符号平均同时保留自对偶投影平方的下界。

强迫零点给逐度量的严格标量估计，却仍需要几何尺度控制才能给统一正改进量。另一方面，允许的等变 Dirac 首项可以在固定度量的辅助 SW 系统中完成到任意形式阶。这排除了仅靠有限阶 Taylor 不相容性完成全局障碍的方案，并将剩余问题定位到实际全局场、振幅和退化尺度。

连续推导见[Wahl 退化中的实际规范场与形式延拓](../research/notes/Wahl_Fields_and_Formal_Completion.md)。

## 10. 各类结论之间的区别

| 需要区分的对象 | 数学关系 |
|---|---|
| 独立的曲率下确界 | 同度量恒等式 $`P=R-S/4`$ 不允许相减两个独立下确界 |
| 非零 Einstein 归一化与 Ricci-flat | $`P=0`$ 包含 Ricci-flat；本项目定义的 $`\mathcal E`$ 在 Ricci-flat 度量上为 $`4`$ |
| 体积塌缩与归一化极值 | $`P_*=0`$ 不自动推出 $`\alpha=0`$；$`\chi=\tau=0`$ 的长圆柱分支给 $`\alpha=1`$ |
| 严格不等式与统一间隙 | 逐度量不能取等号，不排除一列缺陷趋零的度量 |
| 局部曲率积分与全局最优值 | 相对曲率公式含背景、边界、端群及标记项；一般竞争度量的下界须包含这些项 |
| 形式解与精确解 | 逐阶递归及无限阶小残差不蕴含收敛、邻域精确解或全局延拓 |
| cscK 驻定与局部强制 | 核方向保留有限维上同调障碍；显式乘积鞍点排除无条件正强制 |
| 近驻点与光滑取得性 | 变分选择给必要条件；极小序列的紧性、塌缩与奇点消除需独立证明 |
| 非紧存在性与闭刚性 | 完备非紧严格例子给出非紧存在性结论；闭 Goldberg 问题另要求紧致性 |

相应定理、构造及开放问题见各专题，证明原稿见[文献与原稿索引](../catalog/README.md)。
