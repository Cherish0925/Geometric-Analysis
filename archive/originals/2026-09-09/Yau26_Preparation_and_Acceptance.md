## 1. 保留原题，不以工具能力缩小研究目标

原题摘录核对自用户提供的 `two_major_open_problem_list.md` 中 Problem 26；该文件附加的状态评论与推荐路线不当作丘成桐原文或已证明结论。正式论文应进一步保存1982年原版页码和对应扫描。原题的坐标无关表述为：

\[
\forall n\;\exists c_n<C_n\;\forall(M^n,g),\qquad
c_ng\le\operatorname{Ric}_g\le C_ng
\Longrightarrow \exists h,\lambda:\operatorname{Ric}_h=\lambda h.
\]

在紧致、无边界光滑流形上研究光滑正定 Riemannian 度量；记录连通性等采用的约定。结论是底层流形承载某个 Einstein 度量，并不要求输入度量本身 Einstein、输出度量接近输入度量，或输出保留输入的对称性。

原文没有明确写出夹逼常数的符号。应保留原始量词，分别标记正号、负号归一化分支。证明各维正号版本成立可以提供原题所需常数；仅否定一个符号分支不能自动否定原始存在量词。对固定符号的任意小误差反例，必须固定维数，并使误差趋于零，同时排除底层流形上的所有 Einstein 度量。维数随误差变化、排除某个对称族、求解器不收敛，都不足以完成此任务。

将现有定理中的额外条件与原题逐项对照：截面曲率或全曲率控制、非塌缩、注入半径、直径、体积、曲率导数、Sobolev 常数、谱隙、参考 Einstein 度量、复结构等，不能未经证明直接加入原题。研究可使用这些条件形成中间定理，但须标记适用范围。

复用目标服务器已验证的依赖。记录真实版本、解释器路径、构建选项及官方文档版本，不按本文日期猜测“最新版本”，也不为统一版本号强行升级现有环境。

| 数值探索 | NumPy、SciPy、mpmath | 优化、特征值、约化方程、延拓与高精度探索 | 普通浮点和任意精度数值都不能单独作为严格证书 |
| 验证 ODE | CAPD 或经过同等验证的 ODE 后端 | 编译并运行官方用例，再运行有解析解的初值问题与变分方程 | 初值问题工具不自动解决奇异端点、两点边值或全局拼接 |
| PDE 与谱探索 | FEniCSx/DOLFINx、PETSc、SLEPc；相匹配的 MPI/HDF5 等依赖 | 基础椭圆方程、边界条件、离散谱计算与网格加密 | 有限维矩阵谱不能直接替代连续算子谱与反算子界 |
| 形式化证明 | Lean 4、Mathlib、Lake；匹配版本的证明复查工具 | 项目构建、公理依赖输出、关键定理复查 | 不预设全部 Einstein 几何分析已存在于 Mathlib |
| 自动微分与模型搜索 | 复用 PyTorch；确有需要再接 JAX 等 | 与解析导数对照的自动微分、候选优化 | 自动微分和训练损失不能替代严格导数界 |
| 文献、交付与运行记录 | Git、SQLite/JSON、pytest、LaTeX、Poppler/PDF 文本提取、现有搜索接口 | 原文检索、定理定位、版本记录、复现与论文编译 | 引用存在不等于引用定理适用 |

SageManifolds 已包含 Riemann/Ricci/Weyl 等计算能力。[SageManifolds 官方说明](https://sagemanifolds.obspm.fr/) python-flint 提供精确代数和严格误差跟踪。[官方文档](https://python-flint.readthedocs.io/en/latest/) CAPD 提供验证 ODE 积分及变分方程工具。[开发者论文](https://arxiv.org/abs/2010.07097) FEniCSx 的数值环境按其依赖与安装说明准备。[官方安装说明](https://docs.fenicsproject.org/dolfinx/main/python/installation.html)

按用户希望预先全面准备的要求，可将 ODE/PDE 备用环境也提前安装并验收；研究时只加载所需部分。神经网络搜索复用既有 GPU 环境，不要求为本课题训练新大模型或采购额外 GPU。SAT/SMT、额外商用 CAS 和更多拓扑软件在确有对应数学任务时接入，不以安装数量衡量完备性。

### 需要落实到程序中的算法能力

每类能力选择一个合适的成熟实现，写明对象范围并运行有数学对照的用例。表中属于解析证明的方法要提供定义、公式、依赖和适用实例，不能仅凭软件安装声称已实现任意情形。

| 算法能力 | 应支持的操作 | 严格性要求 |
|---|---|---|
| 张量与符号推导 | 指标缩并、符号微分、坐标/非坐标标架公式、带参数的线性化、局部展开 | 简化保留定义域、分母非零与分支条件；随机代入只作排错 |
| 精确代数与约束 | 有理数/代数数、精确线性代数、多项式消元与实根隔离；必要时复用 Gröbner 基等 | 只对所声明的有限代数模型下结论；保留参数、非退化性与实数条件 |
| Ricci 夹逼与矩阵界 | 广义特征值、严格矩阵范数、正定性/半正定性检验 | 区间不能判定的零或临界特征值不强行判定；用精确恒等式处理可识别退化 |
| 连续域不等式 | 自适应区间分割、区间/Taylor 界；多项式情形可采用 Bernstein 等界 | 覆盖整个声明区域及边界；分割耗尽预算返回未完成判断 |

| 验证 ODE 与边值问题 | 初值与变分方程验证积分，结合有限维参数匹配求解具体边值问题 | 单独处理奇异端点与光滑闭合；算法适用的初值范围和时间范围明确 |

## 3. 运行环境与统一入口

以一个 `qiushi-yau26` 命令行入口调用同一份底层实现。Skill 提供任务入口、数学约定、工具能力与证据规则；若 Qiushi 的调用方式需要 MCP，让 MCP 包装这些函数或命令，不另建重复实现。

Sage 使用独立的可复现运行环境；PDE 环境隔离 MPI/PETSc/HDF5 依赖；Lean 固定工具链与 Mathlib 提交。不同解释器通过明确的进程调用与结构化文件交换结果，避免在一个进程中随意混用不兼容的数学库。Python 普通依赖使用现有环境管理工具锁定；有必要才建立新环境。

复用 Qiushi 的任务调度、模型接口、存储和监控。每个任务支持超时、取消、内存上限和长计算检查点。限制并行任务与 BLAS/OpenMP 线程的乘积，先用实际算例测量内存和吞吐，再增加并发。区间后端的编译与舍入设置必须符合其正确性要求，不能因性能优化破坏误差包络。

每个运行记录至少包含：任务与命题标识、精确输入、代码提交、依赖版本、参数、精度或区间设置、随机种子（如适用）、输出、证据文件、运行状态及复现命令。精确数和区间端点不能经普通浮点序列化后丢失精度。代码、规范和结果索引入 Git；大结果与缓存使用既有文件存储，保留内容校验与版本关联。

缓存必须区分输入公式、定义域、假设、精度、代码和环境版本，不能在条件改变后继承旧证书。对正在使用的运行环境采用版本化发布；更新后重新验证受影响能力。Agent 的探索代码不能在未记录的情况下改变独立检查器或验收标准。

模型接口应在目标运行环境中实际调用一次，确认检索、工具执行、长任务查询、文件读写和故障返回均可用。沿用现有重试与调度机制；重试不能把未完成计算改写成成功。CPU/GPU 时间、模型调用成本和峰值内存按现有统计记录，用于安排资源，不作为数学进展指标。

本说明不将任何命令名称视作现有可执行程序。准备 Agent 必须列出已实现、已测试、仅提供适配接口以及尚未实现的功能。

## 4. 统一数学对象与证据格式

不强迫所有抽象证明写成有限坐标数据。允许“显式几何对象”与“带引用和依赖的抽象数学对象”两种输入；需要计算时才要求可计算表示。

**命题对象**：原始陈述、维数与参数量词、符号分支、归一化、全部假设、拟证明结论、相对于26题的逻辑关系。对参数或维数的有限验证范围应直接写在结论中。

**几何对象**：流形与光滑结构、连通性/定向等条件、坐标域或标架、过渡函数或结构系数、度量、参数域、正定性与正则性条件、全局覆盖/商作用/拼接资料。局部模型应明确标记局部，不冒充闭流形。

**算子对象**：原方程、规范选择、函数空间、范数、边界或端点条件、参数、核与约束处理。非坐标标架需要结构系数，不能直接套坐标标架公式。约化方程必须附约化与原方程之间的证明。

**证据对象**：准确陈述、覆盖区域、输入与方法、精确结果或误差包络、依赖定理与适用条件、未证事项、证书及检查器。把“探索结果”“严格有限计算”“条件性引理”“完整定理”分别记录。

运行状态与数学状态分开。进程成功退出不能自动标记命题成立；超时、数值失败或区间过宽表示尚未完成判断。一个条件性命题可以得到严格证明，但依赖尚未消除时不能升级为无条件结论。

### Harness 中防止幻觉与误报的具体要求

- 引用定理绑定原文版本、位置、完整假设与实际结论；检索摘要或模型记忆不直接进入已验证依赖。
- 每个结论绑定对象、量词、定义域和证据；改变问题、附加假设或限制维数必须体现在陈述中。
- 检查器从保存的数学输入重算，不以模型评价、多个 Agent 投票或搜索器置信度作证据。
- 程序错误、运行中断、未找到解、区间不能判定与数学否定分别记录。
- 推导中的未证引理、外部定理和计算证书保留可查询依赖；存在循环或缺口时，总结不能称为完整证明。
- 已知结果复现、经典公式推论、数值候选和原创结果分别标记。阶段成果必须说明距原题的逻辑缺口。
- 对同一瓶颈反复得到未决结果时，检查表示、引理或路线；扩大搜索预算应有具体数学理由。证据规则不能预先限定发现方法或禁用纯解析证明。

以上机制用于降低错误和让错误可定位，不宣称可以彻底消除一切幻觉。

## 5. 脚本职责与实际能力

| 接口职责 | 输入与输出要求 | 验收重点 |
|---|---|---|
| `doctor` | 枚举版本与真实路径，执行功能用例，给出能力报告 | 导入成功、算法运行和数学用例通过分别记录 |
| `curvature` | 从几何对象计算联络、Riemann/Ricci/Weyl、标量曲率与所需导数 | 符号约定、坐标/标架变换、度量相容性、曲率恒等式 |
| `linearize` | 输出明确规范下的线性化、约束及余项表达 | 参数导数与空间导数区分，不能未经证明假定算子可逆 |
| `pinching` | 对定义域和参数域给出 Ricci 相对度量的界 | 全域覆盖，不能使用任意坐标下 Ricci 矩阵的普通特征值 |
| `search` | 在声明的候选空间探索、延拓并保存候选 | 搜索范围明确；近似候选不能直接升级为精确对象 |
| `certify` | 按已实现的方法生成精确代数、区间、根或演化的证书 | 逐类声明支持的对象和误差项，不声称是万能证明器 |
| `obstruction` | 整理不变量、适用定理、条件证据与未证依赖 | 必须区分排除某类度量与排除所有 Einstein 度量 |
| `verify` | 从固定输入和证据独立复查，并报告逻辑适用范围 | 不接受搜索器的成功标签作为证明；损坏证据要拒绝 |

这些是接口职责，不强制拆成八个独立程序。可在一个包内按实际复杂度组织，避免空目录、占位函数和没有用途的重复包装。

夹逼应处理
\[
\operatorname{Ric}_g v=\mu gv,
\]
或证明两个对称双线性形式 \(\operatorname{Ric}_g-cg\) 和 \(Cg-\operatorname{Ric}_g\) 半正定。小误差范数必须明确是算子范数还是其他范数，转换系数须写出。对等号或零特征值，区间不能判定时保留未决，不将舍入误差当作严格正性。

全域验证需处理全部坐标片、参数边界、分母不为零、坐标退化点以及必要的无穷端或渐近极限。有限采样只用于发现问题；对奇异坐标使用有效的替代坐标、正则化或解析延拓论证。

## 6. 数值近似到严格数学之间的桥梁

仅有 PDE/ODE 求解器与区间算术仍不够。若选择从近似解得到精确解的路线，必须明确适用的后验存在性定理，并为下列项目提供证明或可复查证书：

- 控制在指定函数空间范数中的残差，包括数值舍入、离散化、级数截断和尾部误差。
- 在正确规范、边界条件和约束下处理线性算子的核，给出所需逆或近似逆的界。
- 控制非线性余项并验证固定点、Newton–Kantorovich 或所用定理的实际条件。
- 证明修正后的解仍为正定度量，满足所需正则性、全局相容性与端点条件。
- 证明所得对象解决原方程；若先解决规范固定方程，还须消除规范引入的额外可能性。

工具可以复用有限维区间 Newton、验证积分和误差估计，但不能预装一个适用于所有 Einstein 问题的通用后验定理。已安装后端、已实现特定证明方法、已完成某个数学证明必须分别报告。

Buttsworth–Hodgkinson 的计算机辅助工作同时包含近似度量构造和严格扰动存在性论证，可作为方法学习材料。[原论文](https://arxiv.org/abs/2412.01184) 2026年的双重翘曲积研究进一步提供计算机辅助构造方法，但其对称性与维数条件仍须保留。[预印本](https://arxiv.org/abs/2606.05519) 这些工作不是26题的通用求解程序。

## 7. 文献与证明认知准备

为每项关键文献保存准确版本、原始链接、定理位置、完整假设、结论和证明使用的额外几何控制。区分“论文使用某个条件”和“已证明该条件不可移除”。用户整理稿中的策略判断不作为定理输入。

优先理解：Ricci 与完整曲率的差异；规范与微分同胚自由度；几何退化与紧性；局部稳定性和全局存在性的差异；已知不存在性障碍的适用范围。根据证据选择研究路线，不预先断言反例构造一定比存在性证明容易。

Jäckel 的负曲率有效稳定性工作仍有额外截面曲率、导数、薄部几何等假设，适合分析哪些估计依赖哪些条件。[论文](https://arxiv.org/abs/2502.16692) Gromov–Thurston 流形上的相关构造表明，不承载局部对称度量并不自动排除 Einstein 度量。[论文](https://arxiv.org/abs/2411.12956)

不存在性论证由具体数学定理支撑，软件只辅助核对可计算条件。计算普通拓扑不变量不等于自动获得 Seiberg–Witten 等更深结构。也不能把不承载指定 Kähler 类中的特殊度量，改写成不承载任何 Riemannian Einstein 度量。

四维候选还应先做兼容性检查：对紧致定向四维流形，若 \(\|\operatorname{Ric}_g-\sigma g\|_{\mathrm{op},\infty}\le1/4\)、\(\sigma=\pm1\)，则已经有 \(2\chi(M)>3|\tau(M)|\)。事实上 \(|s|\ge3\)，无迹 Ricci 的张量范数 \(|E|\le1/2\)，从而 \(s^2/24-|E|^2/2\ge1/4>0\)，代入经典 Euler 特征数与签名曲率积分公式即得结论。因此不能在违反 Hitchin–Thorpe 不等式的流形上搜索这类任意紧夹逼。这是经典公式的直接推论，只用于排除无效路线，不标为原创研究成果。[公式来源](https://www.math.stonybrook.edu/~claude/lmo.pdf)

Lean 验收必须核对命题的数学含义、依赖与公理。仅构建成功不足以排除依赖中的 `sorry` 或自定义公理；针对实际工具链运行公理检查及适用的复查工具。原生计算带来的信任依赖按当前 Lean 版本记录，不能只检查某一个历史公理名称。[Lean 官方证明验证说明](https://lean-lang.org/doc/reference/latest/ValidatingProofs/)

纯解析证明、严格计算机辅助证明和形式化证明都可以作为研究成果的证据形式；应准确说明各自的检查方式及尚未形式化的部分。无需把尚未获得的全套几何分析形式化库设为启动前提。

## 8. 验收矩阵

以下是目标服务器需要执行的验收，不表示已在本次会话运行。基础和备用能力分别出具实测结果；未通过的项目列入缺项，不能用“全部已安装”覆盖。

| 检查 | 具体用例 | 应得到的结果 |
|---|---|---|
| 环境与互操作 | Sage、Python、严格数值、Lean；备用 ODE/PDE 后端运行各自用例 | 能定位实际版本；精确数、区间和表达式可无损交换 |
| 基准曲率 | 欧氏空间、单位圆球、常截面曲率 \(-1\) 的局部模型 | Ricci 分别为 \(0\)、\((n-1)g\)、\(-(n-1)g\)；局部模型不冒充紧致例子 |
| 非 Einstein 输入 | \(S^2(r_1)\times S^2(r_2)\)，选不等半径 | 相对 Ricci 特征值为 \(1/r_1^2\)、\(1/r_2^2\)，各重数2；输入非 Einstein，但底层流形有 Einstein 度量，因此不是反例 |
| 坐标与尺度 | 同一度量的两套坐标；\(h=ag\)、\(a>0\) | 几何结果一致；Ricci 的协变二阶张量不变，标量曲率和相对 Ricci 特征值除以 \(a\) |
| 张量约定 | 非平凡度量上的度量相容性、曲率对称性及适用的 Bianchi 恒等式 | 精确恒等式成立；人为改变符号或指标应暴露错误 |
| 连续域夹逼 | \(g=I\)、\(A(t)=\mathrm{diag}(1,1+4t(1-t))\)、\(t\in[0,1]\) 的矩阵核测试 | 第二特征值上界2可严格验证；仅检查端点会漏掉内部最大值。该项仅测试矩阵界，不声称 A 是某个度量的 Ricci |
| 精确与区间证据 | 有严格根隔离的多项式、已知积分、接近零的表达式 | 真结论可复查；过宽区间返回未完成判断；高精度近似不会自动变成精确证书 |
| 有限维存在性 | 适用区间 Newton/Krawczyk 的根问题，以及缺少必要条件的输入 | 前者获得包含正确的证书；后者不输出无条件存在性结论 |
| 全局几何检查 | 正常坐标过渡与故意破坏的过渡；端点光滑性条件缺失的候选 | 正常对象通过声明的检查；不相容或未证明部分被指出 |
| 验证 ODE | 带解析解的初值与变分方程 | 严格包络覆盖解析解；端点或边值条件另外验证 |
| PDE 探索 | 已知解的椭圆方程，离散谱与网格加密 | 数值一致性符合预期；若没有后验误差与连续算子控制，输出保持数值结果状态 |
| 后验存在性方法 | 若宣称已提供某一方法，给出有解析对照的完整小实例 | 残差、逆界、非线性条件和解的适用范围全部可核查；不以单个小实例证明通用性 |
| 不存在性依赖 | 对照具有 Einstein 度量的已知流形，以及缺失关键假设的定理应用 | 不出现假反例；条件缺失不能生成无条件不存在结论 |
| 候选兼容性 | 四维紧 Ricci 夹逼与 Hitchin–Thorpe 违反条件同时被声明的候选 | 提示两组声明不相容，追查曲率计算、拓扑数据或假设 |
| 形式化边界 | 正确小定理、依赖中含 `sorry` 的示例、自定义假设示例 | 正确证明与条件性/未完成证明能区分；检查正式陈述含义 |
| 证据重放与故障 | 改坏证书、改变输入、截断输出、取消后恢复 | 错误与不完整运行被识别；不能继承旧的成功标记 |
| 独立复现 | 在锁定环境中从输入重新执行关键算例 | 精确输出一致，或重新给出有效严格包络；不要求所有浮点结果逐位相同 |

已知算例用于验证软件，不计为研究创新。多轮复核用于解决具体剩余风险；用例充分通过后推进数学研究，不反复增加相同检查次数。
