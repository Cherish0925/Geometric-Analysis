# 01 原命题、量词、归一化与逻辑结构

## 1. 工作命题

本项目采用的工作命题：

> 对每个维数 \(n\)，是否存在只依赖于 \(n\) 的常数 \(c_n<C_n\)，使任何闭、连通、光滑 \(n\)-流形，只要承载某个满足
> \[
> c_ng\le\mathrm{Ric}_g\le C_ng
> \]
> 的 metric，就必然在**同一 smooth manifold**上承载某个 Einstein metric？

输出 Einstein metric 不要求接近输入 metric。

原始 1982 Problem 26 的题页/原句仍未逐字核定，所以这里称“工作命题”。

## 2. 缩放

若
\[
\widehat g=\lambda g,\quad\lambda>0,
\]
则作为 \((0,2)\) tensor，
\[
\mathrm{Ric}_{\widehat g}=\mathrm{Ric}_g,
\]
但 Ricci endomorphism
\[
\widehat g^{-1}\mathrm{Ric}_{\widehat g}
=
\lambda^{-1}g^{-1}\mathrm{Ric}_g.
\]

因此任何不跨零的 interval 可归一化到 \(+I\) 或 \(-I\) 附近。

## 3. normalized branch

定义
\[
\delta_\sigma(g)
=
\|g^{-1}(\mathrm{Ric}_g-\sigma g)\|_{L^\infty,\mathrm{op}},
\qquad\sigma=\pm1.
\]

\(P_n^\sigma(\varepsilon)\) 表示：
> 若 \(\delta_\sigma(g)<\varepsilon\)，则底层 smooth manifold 承载某个 Einstein metric。

在当前工作框架下，固定维数的非退化 interval 问题被化为至少一个同号 branch 的 forcing 问题。

## 4. 证明与反驳的量词

- **证明**固定维数 interval proposition：只需找到有效的 \(P_n^+\) 或 \(P_n^-\)。
- **反驳**固定维数 proposition：必须让所有允许 interval 失败；在 normalized 语言中，不能只给一个负分支反例。
- “某条 gluing branch 附近无 Einstein”不够，因为输出 metric 可以位于 metric space 远处。

这是全项目最重要的量词纪律。

## 5. 跨零 interval

后期 interval audit 进一步指出：如果 interval 跨零或端点触零，缩放可把任意 metric 的 Ricci endomorphism 推向零。于是已知 no-Einstein smooth types 会强烈阻止这种 interval 成为 forcing interval。strict-positive / strict-negative 才分别归入 \(P_n^+\)、\(P_n^-\)。

## 6. 低维

- \(n=2\)：uniformization。
- \(n=3\)：Hamilton/三维几何化提供足够的 Einstein existence 机制；项目把其视为普通数学层面关闭。
- 真正困难从 \(n=4\) 开始，因为 Weyl curvature 出现，Ricci 不再控制完整 Riemann curvature。

## 7. 四维第一道 topology filter

Chern–Gauss–Bonnet + signature identities 使足够 tight 的两侧 Ricci pinching 强迫
\[
2\chi>3|\tau|.
\]

因此 HT violating / equality smooth types 不能承载 \(\delta_\sigma\to0\) 序列。

## 8. local obstruction 与 global no-Einstein 的区别

football orbifold resolution 的警告最典型：某条 Eguchi–Hanson desingularization branch 可以被 obstruction 卡住，但 resolution smooth type 可能是 \(S^2\times S^2\)，而它本身有 product Einstein metric。

所以任何 local obstruction 必须再加：
1. global compactness/rigidity，强迫所有 Einstein metrics 落在该 degeneration；或
2. 独立 topology/gauge theorem，排除该 smooth type 上所有 Einstein metrics。
