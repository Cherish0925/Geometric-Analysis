# Yau26 科学续接稿 v2：覆盖补全与原件索引

本版用于替换上一版三份LaTeX的续接入口，但不替换、删除原始研究。

## 三份稿件

- `01_A01_统一拓扑间隙与近Einstein刚性.tex`
- `02_A02_点态近Einstein解消与Weyl匹配.tex`
- `03_A03_全局拓扑兼容与反例闭合.tex`

分工是可调整的组织建议。先读取各自当前工作区和原Step100交接，不要求正在推进的有价值路线一律停止，也不把所有成果强行归属到新的会话编号。

## 接续顺序

先看`00_覆盖审计与修订说明.md`及对应的`审计/A0x_Step100原始交接.md`，再读修订LaTeX。查某个成果时，通过`审计/研究条目覆盖表.tsv`找到来源步骤和稿件位置；通过`审计/300步定位.tsv`、`300步原始任务索引.json`或`全部300步原始交接.txt`读取原任务。随后回原工作区取得真正需要的证明、脚本和数据。

`原始材料/`保存三份完整meta-trace、两份输入ZIP和项目交接MD；`审计/原件校验.tsv`记录与当前上传原件一致的SHA256。`审计/v1原稿/`保留原版三份LaTeX，差分文件列出改动。`审计/归档B1-B21原文.md`是原归档成果总表的原文副本，其中证据等级并非本次重新核准。

## 编译

每个LaTeX使用ctex/Fandol字体和XeLaTeX，可独立编译，不依赖另两份稿件。典型命令：

```sh
xelatex -interaction=nonstopmode -halt-on-error "01_A01_统一拓扑间隙与近Einstein刚性.tex"
xelatex -interaction=nonstopmode -halt-on-error "01_A01_统一拓扑间隙与近Einstein刚性.tex"
```

另外两份同样编译。不要将旧版PDF与v2 LaTeX视为同一版本。本包不附旧PDF、字体文件或编译临时文件。

## 版本边界

本版做的是来源覆盖复核与补全，不是新一轮完整数学证明认证或外部查新。没有实际取得的原稿仍明确标为待取得；本版编辑者新增的估计留在可选附录或标注段落，不代替原成果。详细范围见覆盖审计说明。
