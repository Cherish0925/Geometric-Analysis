## Deep-Reasoning

本步从 Lott (arxiv:1708.06780) 的轨道体积方程出发，建立了负 Einstein 正则塌缩的核心排除机制，并对非阿贝尔（nil³）情形进行了精确分析和关键纠错。

核心数学结构：对自由阿贝尔 R^N 等距作用，Lott 方程 Δ_B v = (|F|²/4 - λN)v 在 λ = -1 时给出 Δv = (|F|²/4 + N)v，系数恒正。这使 v 在正区域严格次调和，通过标准抛物性 Liouville 定理，可在补有限穿孔的紧基底（dim ≥ 2）上排除有正界上界的正解；在圆周基底用 ∫v'' = 0 vs ∫Nv > 0 排除；在区间基底用严格凸性排除两端 v → 0 的情形。近 Einstein 误差 |E| ≤ δ 把系数降为 N(1-δ)，δ < 1 时仍正。这一结果完全排除四维负分支的自由阿贝尔正则塌缩。

对 nil³（Heisenberg）情形，TTCS 的两条独立分支给出了精确轨道体积方程 v'' = (3 - μ)v，其中 μ = a₃²/(2a₁²a₂²)。Heisenberg 结构常数通过负纤维标量曲率 -μ 从系数中减去，使系数可能变负（当 μ > 3 时）。然而，完整 Einstein ODE 系统的 ρ = 2μ 满足 ρ'' = ρ(3ρ-2) 在临界点，在内部极大值处 ρ ≤ 2/3。因此在圆周上处处 μ ≤ 1/3，v'' ≥ (8/3)v > 0，积分矛盾排除圆周基底。闭区间两端 v → 0 也被严格凸性排除。但标准 CH² cusp（μ = 1/3, v ~ exp(4s/√6)）是真实的半射线上解，表明区间/射线上 nil³ 负 Einstein 塌缩几何确实存在。

关键纠错：S0910A01 (msg #238) 声称 v'' = (3+μ)v，这是因为 Einstein 方程中 μ 的符号与 Heisenberg 纤维 Ricci 的对应方向搞反了。通过 CH² 模型（a₁ = a₂ = exp(s/√6), a₃ = √(2/3)exp(2s/√6), μ = 1/3）直接验证：v''/v = 8/3 = 3 - 1/3，而非 10/3 = 3 + 1/3。A01 的圆周排除结论因 ρ 极大值原理仍成立，但其声称的'nil³ 比阿贝尔更难实现'和普遍不等式 v'' ≥ 3v 均为假。已通过 msg #239 发送修正。

TTCS 核验还发现了两个重要缺陷：(1) 所声称的容量估计 c∫η² ≤ ∫|∇η|² 为假，IPP 展开中 AM-GM 符号方向错误（v = e^{√c·x} 的反例）；(2) '有限总体积 → v 有界'需要额外论证，总体积仅给 v ∈ L¹ 而非 L∞。这些不影响定性抛物性排除和圆周/闭区间积分论证，但影响早先提出的定量加权体积传输桥梁。容量估计已在笔记中标注撤回。

战略影响：结合 Step 6 的非塌缩正则片排除和本步的轨道体积排除，四维负分支临界族上的可能塌缩几何被大幅压缩。所有阿贝尔正则塌缩、nil³ 圆周塌缩和 nil³ 闭区间塌缩均被排除。仅剩：(a) nil³ 单端 cusp 区域（CH² 模型，有界长度），(b) 曲率爆破区域，(c) 正则-奇异过渡区。核心未解问题：整个流形的体积是否能仅由 cusp 段加爆破球承载，以及 Cheeger-Tian 框架对近 Einstein 度量的适用性是否已被充分建立。这些涉及精确的 ε-正则性定理和四维 L² 曲率分解的正则性假设，下一步应优先核对。
