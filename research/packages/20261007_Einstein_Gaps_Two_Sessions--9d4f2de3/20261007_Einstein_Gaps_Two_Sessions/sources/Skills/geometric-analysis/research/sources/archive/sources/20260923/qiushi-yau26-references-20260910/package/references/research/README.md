## 后续维护

新的完整调查或实质修订使用新的日期目录，同日修订可加 `-r2` 等版本后缀。
保留原文件及此前版本；在此索引中更新入口，简述新增认识、修正内容和来源变化。
每版记录来源与校验值，TeX 和 PDF 保持对应。更新动作由维护者明确完成，
不是自动联网刷新，也不要求每个 Session 另存一份。

同一用户的会话共用这份资料；各会话的新推导、程序、候选与修改建议先保存在
各自 workspace，通过已有协作机制交流，再把成熟内容整理进新版。
更新工具软件时合并维护本目录，不用基础 Skill 模板覆盖已有研究资料。
