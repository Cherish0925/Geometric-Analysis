# 续研 C 阅读入口

主文件：`O10_Finite_Density_Fifth_Line.md`。

本轮形成的证明连接是：在原强流和第一延拓成立的条件下，排除任意**固定有限**平均反手性 Weyl 能量下的 O10 零端序列；从而对每个有限 Euler 密度 B 得到 c(B)>0。不是只将 39/4 再增加一个数值。

主要新分析位于主文件第3–6节。第一延拓在前轮已证明，却没有进入 50/3 谱阈值主证明；这次使用它识别剩余导数的 L^5 线丛归属。

`inherited_proofs/` 是为复核方便原样复制的前置文件，仍保留它们写成时的旧终点状态，不将这些旧状态与本轮结论混写。`SOURCE_AND_STATUS.json` 记录来源和依赖。

`verify_negative_line.py` 只核验有限代数，不能替代全局弱测试和极限证明。核心独立复核点：线丛次数5、保留相位流的Cartan式、下幅度截断、弱CR对偶测试及 +10/3 的符号。

完全删除 B 的 O10，以及 O11 的全局最优首项，仍没有在本轮解决。
