### Corollary 2.8

For any 4-dimensional para-Kähler structure ( _M_, _g_, _K_) the pseudo-Riemannian holonomy of the metric _g_ is reduced from \\({\\mathbf {SO}}\_{\\mathbf {2,2}}\\) to \\(\\mathbf {GL}\_2({\\mathbb {R}})\\) via the representation _T_ in ( [2.17](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ19)). This holonomy reduction is equivalent to the property that _K_ is parallel with respect to the Levi-Civita connection \\(\\nabla \\) of _g_.

#### 2.3.3 Para-Kähler structure in a coordinate system

One of the features of Kähler metrics is that they can be locally expressed in terms of a function, called the _Kähler potential_. An analogous feature for the para-Kähler structures in 4 dimensions is described in the following two propositions.

### Proposition 2.14

Let \\({\\mathcal {U}}\\) be an open set of \\({\\mathbb {R}}^4\\), and let ( _a_, _b_, _x_, _y_) be Cartesian coordinates in \\({\\mathcal {U}}\\). Consider a real-valued sufficiently differentiable function \\(V=V(a,b,x,y)\\) on \\({\\mathcal {U}}\\) such that

$$\\begin{aligned} \\det \\begin{pmatrix} V\_{ax}&{} V\_{ay}\\\ V\_{bx}&{}V\_{by}\\end{pmatrix}\\ne 0\\quad \\mathrm {in}\\quad {{\\mathcal {U}}}. \\end{aligned}$$

Define

$$\\begin{aligned} \\begin{aligned} g=&~2\\mathrm{d}a~(V\_{ax}\\mathrm{d}x +V\_{ay}\\mathrm{d}y)+2\\mathrm{d}b~(V\_{bx}\\mathrm{d}x+V\_{by}\\mathrm{d}y),\\\ K=&~\\partial \_a\\otimes \\mathrm{d}a+\\partial \_b\\otimes \\mathrm{d}b-\\partial \_x\\otimes \\mathrm{d}x-\\partial \_y\\otimes \\mathrm{d}y,\\\ \\rho =&~\\mathrm{d}a\\wedge (V\_{ax}\\mathrm{d}x +V\_{ay}\\mathrm{d}y)+\\mathrm{d}b\\wedge (V\_{bx}\\mathrm{d}x+V\_{by}\\mathrm{d}y). \\end{aligned} \\end{aligned}$$

Then the pair ( _g_, _K_) defines a para-Kähler structure on \\({\\mathcal {U}}\\) with \\(\\rho (\\cdot ,\\cdot )=g(K(\\cdot ),\\cdot )\\).

The para-Kähler structure \\(({{\\mathcal {U}}},g,K)\\) is Einstein i.e. \\(Ric(g)=\\Lambda g,\\) if and only if the potential function _V_ satisfies

$$\\begin{aligned} \\det \\begin{pmatrix} V\_{ax}&{} V\_{ay}\\\ V\_{bx}&{}V\_{by}\\end{pmatrix}=c\_1 c\_2~ \\mathrm {e}^{-\\Lambda V} \\end{aligned}$$

(2.29)


for a real number \\(\\Lambda \\) and real-valued functions \\(c\_1=c\_1(a,b)\\), \\(c\_2=c\_2(x,y).\\)

### Proof

In the adapted coframe

$$\\begin{aligned} \\begin{aligned} \\alpha ^1&=\\mathrm{d}a,\\qquad&\\alpha ^2&=\\mathrm{d}b\\\ {\\bar{\\alpha }}{}^1&=V\_{ax}\\mathrm{d}x+V\_{ay}\\mathrm{d}y,\\qquad&{\\bar{\\alpha }}{}^2&=V\_{bx}\\mathrm{d}x+V\_{by}\\mathrm{d}y, \\end{aligned} \\end{aligned}$$

the 1-forms \\(\\Gamma ^a\_{~b}\\), constituting the \\({{\\mathfrak {g}}}{{\\mathfrak {l}}}\_2({\\mathbb {R}})\\) part of the Levi-Civita connection, read

$$\\begin{aligned} \\begin{aligned} \\Gamma ^1{}\_1=&\\frac{V\_{aay}V\_{bx}-V\_{aax}V\_{by}}{V\_{ay}V\_{bx}-V\_{ax}V\_{by}}\\alpha ^1+\\frac{V\_{aby}V\_{bx}-V\_{abx}V\_{by}}{V\_{ay}V\_{bx}-V\_{ax}V\_{by}}\\alpha ^2\\\ \\Gamma ^1{}\_2=&\\frac{V\_{aby}V\_{bx}-V\_{abx}V\_{by}}{V\_{ay}V\_{bx}-V\_{ax}V\_{by}}\\alpha ^1+\\frac{V\_{bby}V\_{bx}-V\_{bbx}V\_{by}}{V\_{ay}V\_{bx}-V\_{ax}V\_{by}}\\alpha ^2\\\ \\Gamma ^2{}\_1=&\\frac{V\_{aay}V\_{ax}-V\_{aax}V\_{ay}}{-V\_{ay}V\_{bx}+V\_{ax}V\_{by}}\\alpha ^1+\\frac{V\_{aby}V\_{ax}-V\_{abx}V\_{ay}}{-V\_{ay}V\_{bx}+V\_{ax}V\_{by}}\\alpha ^2\\\ \\Gamma ^2{}\_2=&\\frac{V\_{aby}V\_{ax}-V\_{abx}V\_{ay}}{-V\_{ay}V\_{bx}+V\_{ax}V\_{by}}\\alpha ^1+\\frac{V\_{bby}V\_{ax}-V\_{bbx}V\_{ay}}{-V\_{ay}V\_{bx}+V\_{ax}V\_{by}}\\alpha ^2. \\end{aligned} \\end{aligned}$$

It is straightforward to check that \\(\\mathrm{d}\\rho =0\\), and \\(\\Gamma ^1{}\_4=\\Gamma ^4{}\_1=0\\), as it should be for the Levi-Civita connection in an adapted coframe of a para-Kähler structure.

For the calculation of the Ricci tensor it is more convenient to work in the coordinate frame \\((\\mathrm{d}a,\\mathrm{d}b,\\mathrm{d}x, \\mathrm{d}y)\\) rather than in the adapted frame \\((\\alpha ^1,\\alpha ^2,{\\bar{\\alpha }}{}^1,{\\bar{\\alpha }}{}^2)\\). Thus, we need to display the Levi-Civita connection 1-forms in the coordinate frame as well. Let us use the following notation for the coordinates

$$\\begin{aligned} x^A=(a,b), \\quad x^{{\\dot{A}}}=(x,y),\\quad A=1,2,\\quad {\\dot{A}}=1,2. \\end{aligned}$$

It follows that

$$\\begin{aligned} \\Gamma ^A{}\_{{\\dot{A}}}=\\Gamma ^{{\\dot{A}}}{}\_A=0, \\end{aligned}$$

and the connection 1-forms \\(\\Gamma ^A{}\_B\\) and \\(\\Gamma ^{{\\dot{A}}}{}\_{{\\dot{B}}}\\) are given by ( [A.1](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ103)) in the Appendix.

Using the expressions for the Levi-Civita connection in ( [A.1](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ103)) the curvature can be calculated easily and the Ricci tensor satisfies

$$\\begin{aligned} R\_{AB}=R\_{{\\dot{A}}{\\dot{B}}}=0, \\end{aligned}$$

and

$$\\begin{aligned} R\_{A{\\dot{A}}}=R\_{{\\dot{A}}A}=-\\frac{\\partial ^2}{\\partial \_{x^A}\\partial \_{x^{{\\dot{A}}}}}\\log \\big (V\_{ax}V\_{by}-V\_{ay}V\_{bx}\\big ). \\end{aligned}$$

Since in the \\((A,{\\dot{A}})\\) notation the metric _g_ reads as

$$\\begin{aligned} g=\\sum \_{A,{\\dot{A}}=1,2}\\frac{\\partial ^2V}{\\partial \_{x^A}\\partial \_{x^{{\\dot{A}}}}}\\left( \\mathrm{d}x^A\\otimes \\mathrm{d}x^{{\\dot{A}}}+\\mathrm{d}x^{{\\dot{A}}}\\otimes \\mathrm{d}x^A\\right) , \\end{aligned}$$

the Einstein equations are

$$\\begin{aligned} -\\frac{\\partial ^2}{\\partial \_{x^A}\\partial \_{x^{{\\dot{A}}}}}\\log \\left( V\_{ax}V\_{by}-V\_{ay}V\_{bx}\\right) =\\Lambda ~\\frac{\\partial ^2V}{\\partial \_{x^A}\\partial \_{x^{{\\dot{A}}}}}, \\end{aligned}$$

which after integration give

$$\\begin{aligned} V\_{ax}V\_{by}-V\_{ay}V\_{bx}=c\_1 c\_2~\\mathrm {e}^{-\\Lambda V}. \\end{aligned}$$

\\(\\square \\)

There is a converse to this proposition:

### Proposition 2.15

Every para-Kähler structure ( _M_, _g_, _K_) in dimension four is locally expressible in terms of a para-Kähler potential function _V_ as in Proposition [2.14](https://link.springer.com/article/10.1007/s10711-021-00665-4#FPar18).

### Proof

The integrability of the distributions \\({\\mathscr {H}}=\\mathrm {Ker}\\{\\alpha ^1,\\alpha ^2\\}\\) and \\({\\bar{{\\mathscr {H}}}}=\\mathrm {Ker}\\{{\\bar{\\alpha }}{}^1,{\\bar{\\alpha }}{}^2\\}\\) in a para-Kähler structure implies that in some neighbourhood \\({{\\mathcal {U}}}\\subset M\\) there exists a coordinate system ( _a_, _b_, _x_, _y_) such that

$$\\begin{aligned} \\begin{matrix} \\alpha ^1=A\_1\\mathrm{d}a+B\_1\\mathrm{d}b,\\quad &{}\\alpha ^2=A\_2\\mathrm{d}a+B\_2\\mathrm{d}b\\\ {\\bar{\\alpha }}{}^1=P\_1\\mathrm{d}x+Q\_1\\mathrm{d}y,\\quad &{}{\\bar{\\alpha }}{}^2=P\_2\\mathrm{d}x+Q\_2\\mathrm{d}y, \\end{matrix} \\end{aligned}$$

for some functions \\(A\_i,B\_i,P\_i,Q\_i\\) defined in \\({\\mathcal {U}}\\). Since the coframe \\((\\alpha ^1,\\alpha ^2,{\\bar{\\alpha }}{}^1,{\\bar{\\alpha }}{}^2)\\) is defined up to the \\(\\mathbf {GL}\_2({\\mathbb {R}})\\) action ( [2.17](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ19)), we can use this transformation to bring the coframe into the form

$$\\begin{aligned} \\begin{matrix} \\alpha ^1=\\mathrm{d}a,\\quad &{}\\alpha ^2=\\mathrm{d}b\\\ {\\bar{\\alpha }}{}^1=P\\mathrm{d}x+Q\\mathrm{d}y,\\quad &{}{\\bar{\\alpha }}{}^2=R\\mathrm{d}x+S\\mathrm{d}y, \\end{matrix} \\end{aligned}$$

with new functions _P_, _Q_, _R_, _S_ on \\({\\mathcal {U}}\\) such that \\(PS-QR\\ne 0\\). In this new adapted frame we have \\(\\mathrm{d}\\alpha ^1=0\\), \\(\\mathrm{d}\\alpha ^2=0\\). Inserting this into ( [2.8](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ10)) with \\(\\Gamma ^1\_4=\\Gamma ^4\_1=0,\\) we get

$$ \\begin{aligned} \\Gamma ^1{}\_1\\wedge \\alpha ^1+\\Gamma ^1{}\_2\\wedge \\alpha ^2=0\\quad \\& \\quad \\Gamma ^2{}\_1\\wedge \\alpha ^1+\\Gamma ^2{}\_2\\wedge \\alpha ^2=0, \\end{aligned}$$

which implies

$$\\begin{aligned} \\begin{aligned} \\Gamma ^1{}\_1&=a\_1\\alpha ^1+a\_2\\alpha ^2,\\qquad \\Gamma ^1{}\_2=a\_3\\alpha ^1+a\_4\\alpha ^2\\\ \\Gamma ^2{}\_1&=a\_5\\alpha ^1+a\_6\\alpha ^2,\\qquad \\Gamma ^2{}\_2=a\_7\\alpha ^1+a\_8\\alpha ^2, \\end{aligned} \\end{aligned}$$

for some unknown functions \\(a\_1,a\_2,\\dots ,a\_8\\) on \\({\\mathcal {U}}\\). Inserting this back into the last two of the structure Eq. ( [2.8](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ10)) gives

$$\\begin{aligned} \\begin{aligned} 0&=(Q\_x-P\_y)\\mathrm{d}x\\wedge \\mathrm{d}y\\\ {}&\\quad +\\big (P\_b-a\_2P-a\_6R\\big )\\mathrm{d}b\\wedge \\mathrm{d}x+\\big (Q\_b-a\_2Q-a\_6S\\big )\\mathrm{d}b\\wedge \\mathrm{d}y\\\&\\quad +\\big (P\_a-a\_1P-a\_5R\\big )\\mathrm{d}a\\wedge \\mathrm{d}x+\\big (Q\_a-a\_1Q-a\_5S\\big )\\mathrm{d}a\\wedge \\mathrm{d}y\\\ 0=&(S\_x-R\_y)\\mathrm{d}x\\wedge \\mathrm{d}y\\\ {}&\\quad + \\big (R\_b-a\_8R-a\_4P\\big )\\mathrm{d}b\\wedge \\mathrm{d}x+\\big (S\_b-a\_8S-a\_4Q\\big )\\mathrm{d}b\\wedge \\mathrm{d}y\\\ {}&\\quad +\\big (R\_a-a\_7R-a\_3P\\big )\\mathrm{d}a\\wedge \\mathrm{d}x+\\big (S\_a-a\_7S-a\_3Q\\big )\\mathrm{d}a\\wedge \\mathrm{d}y. \\end{aligned} \\end{aligned}$$

This in particular means that

$$\\begin{aligned} (Q\_x-P\_y)=0\\quad \\mathrm {and}\\quad (S\_x-R\_y)=0. \\end{aligned}$$

As a result, locally, there exist functions _U_ and _W_ on \\({\\mathcal {U}}\\) such that

$$\\begin{aligned} Q=U\_y,\\quad P=U\_x,\\quad S=W\_y,\\quad R=W\_x. \\end{aligned}$$

Thus, one obtains

$$\\begin{aligned}\\begin{matrix} \\alpha ^1=\\mathrm{d}a,\\quad &{}\\alpha ^2=\\mathrm{d}b\\\ {\\bar{\\alpha }}{}^1=U\_x\\mathrm{d}x+U\_y\\mathrm{d}y,\\quad &{}{\\bar{\\alpha }}{}^2=W\_x\\mathrm{d}x+W\_y\\mathrm{d}y. \\end{matrix}\\end{aligned}$$

Since the 2-form \\(\\rho \\) is given by

$$\\begin{aligned} \\rho =\\alpha ^1\\wedge {\\bar{\\alpha }}{}^1+\\alpha ^2\\wedge {\\bar{\\alpha }}{}^2, \\end{aligned}$$

the para-Kähler condition \\(\\mathrm{d}\\rho =0\\) implies

$$\\begin{aligned} 0=\\mathrm{d}\\rho =(W\_a-U\_b)\_y\\mathrm{d}a\\wedge \\mathrm{d}b\\wedge \\mathrm{d}y+(W\_a-U\_b)\_x\\mathrm{d}a\\wedge \\mathrm{d}b\\wedge \\mathrm{d}x. \\end{aligned}$$

This means that \\(W\_a-U\_b=f(a,b)\\) for some function _f_ of variables _a_, _b_ only. But since in the coframe \\((\\alpha ^1,\\alpha ^2,{\\bar{\\alpha }}{}^1,{\\bar{\\alpha }}{}^2)\\) functions _W_ and _U_ appear only in terms of their _x_ and _y_ derivatives, they can be chosen so that \\(f(a,b)\\equiv 0.\\) Hence there exists a differentiable function \\(V=V(a,b,x,y)\\) on \\({\\mathcal {U}}\\) such that

$$\\begin{aligned} W=V\_b\\quad \\mathrm {and}\\quad U=V\_a. \\end{aligned}$$

Thus, the adapted coframe can be expressed as

$$\\begin{aligned} \\begin{matrix} \\alpha ^1=\\mathrm{d}a,\\quad &{}\\alpha ^2=\\mathrm{d}b,\\\ {\\bar{\\alpha }}{}^1=V\_{ax}\\mathrm{d}x+V\_{ay}\\mathrm{d}y,\\quad &{}{\\bar{\\alpha }}{}^2=V\_{bx}\\mathrm{d}x+V\_{by}\\mathrm{d}y. \\end{matrix} \\end{aligned}$$

Expressing _g_, _K_ and \\(\\rho \\) in terms of the adapted coframe as in ( [2.14](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ16))–( [2.15](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ17)) gives the Proposition. \\(\\square \\)

#### 2.3.4 Homogeneous models

Two particular solutions of the Einstein condition ( [2.29](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ36)) are given by the potentials

1. (i)
\\(V\_1=-\\frac{1}{\\Psi \_2'}\\log (b+a x-y)\\),

2. (ii)
\\(V\_2=-\\frac{2}{3\\Psi \_2'}\\log \\big ((1-\\tfrac{3}{2} \\Psi \_2' ax)(1-\\tfrac{3}{2}\\Psi \_2'by)\\big )\\),


where \\(\\Psi \_2'=\\mathrm {const}\\ne 0\\).

Both potentials are solutions of ( [2.29](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ36)) with \\(\\Lambda =-3\\Psi \_2'\\) and \\(c\_1c\_2=\\tfrac{1}{\\Psi \_2'{}^2}\\) for \\(V\_1\\), and \\(c\_1c\_2=1\\) for \\(V\_2\\). Let the para-Kähler structure \\((g\_i,K\_i,\\rho \_i)\\) correspond to \\(V\_i\\) where \\(i=1,2.\\) Then, in an open set of \\({\\mathbb {R}}^4\\) parametrized by ( _a_, _b_, _x_, _y_) one finds

$$\\begin{aligned} K\_1=K\_2=\\partial \_a\\otimes \\mathrm{d}a+\\partial \_b\\otimes \\mathrm{d}b-\\partial \_x\\otimes \\mathrm{d}x-\\partial \_y\\otimes \\mathrm{d}y. \\end{aligned}$$

Straightforward computation gives

$$\\begin{aligned} \\begin{aligned} g\_1=&\\textstyle {\\frac{2\\mathrm{d}a \\big ((y-b)\\mathrm{d}x-x\\mathrm{d}y\\big )+2\\mathrm{d}b\\big (a\\mathrm{d}x-\\mathrm{d}y\\big )}{\\Psi \_2'(b+a x-y)^2}},\\qquad \\rho \_1=&\\textstyle {\\frac{\\mathrm{d}a \\wedge \\big ((y-b)\\mathrm{d}x-x\\mathrm{d}y\\big )+\\mathrm{d}b\\wedge \\big (a\\mathrm{d}x-\\mathrm{d}y\\big )}{\\Psi \_2'(b+a x-y)^2}} \\end{aligned} \\end{aligned}$$

## 3 Para-Kähler-Einstein (pKE) metrics in dimension 4

This section is the heart of the article, in which we describe pKE structures as Cartan geometries, give an in-depth study when the Petrov type is _real_ and _special_ and provide explicit examples. To be more specific, in Sect. [3.1](https://link.springer.com/article/10.1007/s10711-021-00665-4#Sec18) pKE structures are interpreted as Cartan geometries of type \\((\\mathbf {SL}\_3({\\mathbb {R}}),\\mathbf {GL}\_2({\\mathbb {R}}))\\). If the Einstein constant is \\(-3,\\) then they satisfy the Yang-Mills equations for the associated \\({{\\mathfrak {s}}}{{\\mathfrak {l}}}\_3({\\mathbb {R}})\\)-valued _Cartan_ connection. In Sect. [3.2](https://link.springer.com/article/10.1007/s10711-021-00665-4#Sec19) we focus on pKE structures for which \\(Weyl^-\\) has special real Petrov type and give examples of each type. In particular, we find all homogeneous models, give a local normal form for all real Petrov type _D_ pKE metrics and present examples of real Petrov type _II_ that satisfy Yang-Mills equations. Moreover, we use Cartan-Kähler machinery to find the local generality of all Petrov types assuming analyticity.

### Definition 3.1

A _Cartan geometry_\\(({\\mathcal {G}},S,\\psi ),\\) of type ( _G_, _H_) is a principal _H_-bundle \\({\\mathcal {G}}\\rightarrow S,\\) equipped with a \\({\\mathfrak {g}}\\)-valued 1-form \\({\\mathcal {A}},\\) which is a _Cartan connection_, i.e.,

1. (1)
\\({\\mathcal {A}}\_u:T\_u{\\mathcal {G}}\\rightarrow {\\mathfrak {g}}\\) is linear isomorphism for all \\(u\\in {\\mathcal {G}}.\\)

2. (2)
\\({\\mathcal {A}}\\) is _H_-equivariant, i.e., \\(R\_h^\*{\\mathcal {A}}=\\mathrm {Ad}(h^{-1})\\circ {\\mathcal {A}},\\) where \\(R\_h\\) denotes the right action by \\(h\\in H.\\)

3. (3)
\\({\\mathcal {A}}(X\_v)=v,\\) for every fundamental vector field \\(X\_v\\) of \\(\\tau :{\\mathcal {G}}\\rightarrow S, v\\in {\\mathfrak {h}}.\\)


The curvature of the Cartan connection \\({\\mathcal {A}}\\) is given by \\(K\_{\\mathcal {A}}=\\mathrm {d}{\\mathcal {A}}+ {\\mathcal {A}}{\\,{\\wedge }\\;}{\\mathcal {A}}\\in \\Omega ^2({\\mathcal {G}},{\\mathfrak {g}})\\) which is horizontal and defines the _curvature function_\\(\\kappa \_{\\mathcal {A}}: {\\mathcal {G}}\\rightarrow \\bigwedge ^2({\\mathfrak {g}}/{\\mathfrak {h}})^\*\\otimes {\\mathfrak {g}}.\\)

Every pKE 4-manifold defines a Cartan geometry of type \\((\\mathbf {SL}\_3({\\mathbb {R}}),\\mathbf {GL}\_2({\\mathbb {R}}))\\) for which the structure bundle

### Proof

By ( [3.5](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ41)) and the definition of self-dual and anti-self-dual null planes in ( [2.2](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ3)), it follows that

$$\\begin{aligned} \\Psi '\_2=1\\Longleftrightarrow \*K\_{\\mathcal {A}}=-K\_{\\mathcal {A}}. \\end{aligned}$$

Conversely, it is a matter of straightforward computation to show that \\(D\*K\_{\\mathcal {A}}=0\\) combined with the Bianchi identities ( [3.6](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ42)), or equivalently Eq. ( [A.2](https://link.springer.com/article/10.1007/s10711-021-00665-4#Sec34)), and the EDS ( [3.1](https://link.springer.com/article/10.1007/s10711-021-00665-4#Equ37)) imply \\(\\Psi '\_2=1.\\)\\(\\square \\)

### 3.2 Cartan reduction: homogeneous models, examples and local generality

#### 3.2.2 Petrov type _D_
