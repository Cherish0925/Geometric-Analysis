## 哪些联系改变了研究

1. **从积分预算到同场微分相容性。** 实际规范类提供解和拓扑预算，单解的协变导数、曲率模型与 Bianchi 关系进一步控制近 Einstein 缺陷。N1、I40/I41 和有限密度端点分别处理临界分离、线性尺度与退化端点。
2. **从单取向到共同 Hodge 极化。** 曲面丛的两取向实际类共享同一度量，交叉配对把 Kodaira 斜率逼近序列送入一个固定有限密度端点。应用不依赖一般无密度 O10 的解决。
3. **从固定手术费用到背景耦合。** 真实单元与一般背景的负对数插入降低标准费用，迫使最优性研究允许相应节省。指定轨形的精确极值与其光滑解消的严格较低上界，进一步显示拓扑与允许几何类别的区别。
4. **从非紧存在到紧致刚性。** 完备严格 AKE 例回答 Fino 的存在性问句；闭负 Goldberg 另需整体信息。作用量、零集、Green 势和非塌缩无集中定理记录已经取得的限制。
5. **从局部展开到真实全局场。** Wahl 字符可强迫高阶零点，但许可的辅助 SW 场可逐阶形式补全。剩余问题涉及全局归一化、尺度和填充匹配，单纯提高展开阶数不能代替这些联系。

完整公式与条件分别见[间隙与端点](../../docs/GAPS_AND_ENDPOINTS.md)、[曲率变分](../../docs/CURVATURE_VARIATION.md)、[构造与实现](../../docs/CONSTRUCTIONS_AND_REALIZATION.md)和[几乎 Kähler 几何](../../docs/GOLDBERG.md)。

## 原文件与复用

[服务器来源表](../../catalog/server_sources.json)逐项记录原研究树中的位置、用途及仓库中的实际文件。相同字节的文件共用一份；不同数学版本分别保留。需要运行采用原相对路径的程序或编译模块化论文时，可以恢复对应目录：

```sh
python3 tools/server_sources.py materialize sessions/S1003A01 /tmp/S1003A01
python3 tools/server_sources.py materialize sessions/S1003A02 /tmp/S1003A02
python3 tools/server_sources.py materialize codex /tmp/geometric-analysis-codex
```

输出目录须为空。恢复的是收录的科学源文件；原执行环境中的 `Sessions/`、`Skills/`、`Knowledge/` 引用应按来源表定位。各会话入口列明可重建的大矩阵及对应脚本、参数和已保存结果。

收录包括原始数学笔记、独立论证与纠错、程序、精确结果、数值见证、计算失败所揭示的数学限制、研究目标和科学交接。数据库、凭据、模型调用流水、解释器缓存、空模板和可重建的中间矩阵不作为数学正文复制。范围及尚缺的原始材料见[收录说明](../../docs/COVERAGE.md)。
