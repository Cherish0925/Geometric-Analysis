The scaling implication was made executable in `Sessions/S0910A02/workspace/scripts/step58_biquard_ct_collapse_ledger.py` and saved as `Sessions/S0910A02/workspace/data/step58_biquard_ct_collapse_ledger.json`. Since the compact inserted metric satisfies g_t ~ t eh on the EH core, a (0,2)-tensor with EH norm A has g_t-operator size t^{-1} A. Therefore Biquard Lemma 4.2 gives operator residual <= C t rho^2 <= C t^{1/2} on the transition rho <= t^{-1/4}, and O(t) on the core, after the first obstruction term is killed. A nonzero first obstruction term t lambda o remains order |lambda| |o| in g_t-operator norm on the core. Thus the actual Yau--26 input-metric construction only requires killing the vector first obstruction at every inserted A1 node; higher exact-gluing obstructions of order t^q with q>1 vanish in operator norm and obstruct only exact Einstein gluing, not C^0 Ricci pinching. This partially discharges the previous mixed-wall conditionality: the local/raw Ricci residual estimate is now source-anchored. What remains unresolved is not this local estimate but topology/smooth-type bookkeeping, finite chart compatibility in any chosen pattern, and above all whether the resulting smooth manifold carries some far-away Einstein metric.

The same ledger checked minimal genuinely mixed patterns for both mirrors: one reversed node in the positive (S^2 x S^2)/Z2 four-node model, and one reversed node in the negative (Sigma_2 x Sigma_2)/<iota x iota> thirty-six-node model. In both, R_+=R_-=diag(Lambda,0,0), and choosing zeta=(0,1,0) gives R_+ zeta=R_- zeta=0, whereas zeta=(1,0,0) leaves the obstruction nonzero. This preserves the vector nature of the condition; determinant-zero language is insufficient. For constructing approximate Ricci-pinched inputs, no global inverse, AH boundary transversality, or small-eigenvalue solve is needed. For exact Einstein metrics, those global issues re-enter.

The second route correction concerns Cheeger--Tian regularity. The original JAMS PDF could not be retrieved: AMS returned 403, several guessed public URLs failed, and a final knowledge request misfired. I therefore did not claim direct reading of the original paper. A secondary source, Ge--Jiang 2017, lines 29--36, states the Cheeger--Tian theorem: for a 4-dimensional Einstein manifold with Ric=lambda g, |lambda|<=3, small local integral of |Rm|^2 on B_r(p), r<=1, implies sup_{B_{r/2}} |Rm| <= C r^{-2}, without a volume assumption. This is exactly the collapse-tolerant Einstein theorem the positive-collapse branch would want to transfer, but the Step-11 opposite-warping spike structurally blocks any direct C^0-Ricci analogue. The existing Step-11 data show ||Ric-g||_op ~ Lambda^{-2/3}->0 and local Hessian/L2 curvature energy ~ Lambda^{-4/3}->0 while |Rm|(center) grows like Lambda^{1/3}. At Lambda=500 the saved defect is about 0.0322, the center curvature lower bound about 24.45, and the Hessian-energy proxy about 0.00489. The mechanism is that Einstein metrics satisfy an elliptic curvature system, while mere L^infty Ricci pinching leaves trace-free Hessian channels uncontrolled; opposite warping cancels the Hessian in Ricci but not in Riemann. This is a structural ceiling, not a technical gap to be patched by another regularity theorem.

The third correction is the collapse Chern--Weil ledger. In dimension four, with E=Ric^0 and A_±=int |W^±|^2, the identities give A_± = 2 pi^2 (2 chi ± 3 tau) - 1/2 int(s^2/24 - |E|^2/2). If ||Ric - sigma g||_op -> 0 and Vol -> 0, the final integral tends to zero, so both chiral Weyl energies are asymptotically pinned by topology. For #_k(S^2 x S^2), chi=2k+2 and tau=0, so the total limiting Weyl energy is 8 pi^2(2k+2). The old toric/rod adversary with m=2k+2 rods each contributing about 8 pi^2 exactly saturates this budget. Therefore energy counting alone cannot break positive collapse; any obstruction must prove a forced energy defect in lower-dimensional limits, transition regions, nonmaximal nilpotent topology, or global closure, not a missing topological budget.
